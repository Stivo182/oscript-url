# url

`url` - библиотека OneScript для разбора, построения и изменения URL и относительных ссылок.

Единый класс [`URL`](docs/URL.md) представляет абсолютные адреса и относительные ссылки. Библиотека поддерживает
Unicode, разрешение ссылок относительно базового адреса, нормализацию, сравнение и безопасное изменение
компонентов без сетевых запросов.

Синтаксис и разрешение относительных ссылок основаны на
[RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html), поддержка интернационализированных ссылок - на
[RFC 3987](https://www.rfc-editor.org/rfc/rfc3987.html).

## Возможности

- разбор абсолютных URL и относительных ссылок;
- разрешение ссылок относительно базового URL;
- изменение схемы, серверной части, хоста, порта, пути, запроса и фрагмента;
- нормализация, сравнение, копирование и построение относительных ссылок;
- проверка ограничений схем `http`, `https`, `ws`, `wss` и `ftp`;
- работа с Unicode, IDN и Punycode по UTS #46;
- получение кодированного URI-представления;
- работа с параметрами запроса с сохранением порядка и повторяющихся имён;
- кодирование параметров в формате `application/x-www-form-urlencoded`.

## Требования

- OneScript 2.0.0 или новее;
- OPM для установки зависимостей и сборки пакета.

## Установка

```powershell
opm install url
```

Подключение библиотеки:

```bsl
#Использовать url
```

Для проекта с `packagedef`:

```bsl
Описание.ЗависитОт("url");
```

## Быстрый старт

```bsl
#Использовать url

Адрес = Новый URL("https://example.com/users");

Адрес.ДобавитьСегментПути("42");
Адрес.ПараметрыЗапроса()
    .Установить("q", "hello world")
    .Добавить("include", "orders")
    .Добавить("include", "contacts");

Сообщить(Адрес.ВСтроку());
```

Результат:

```text
https://example.com/users/42?q=hello+world&include=orders&include=contacts
```

Параметры сохраняют порядок добавления и повторяющиеся имена.

## Относительные ссылки

Вторым параметром конструктора `URL` можно передать абсолютный базовый адрес:

```bsl
#Использовать url

Адрес = Новый URL("../users", "https://example.com/api/v1/");
Сообщить(Адрес.ВСтроку());
```

Результат:

```text
https://example.com/api/users
```

Относительная ссылка разрешается по алгоритму [RFC 3986 § 5.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-5.2).

## Безопасный разбор

Конструктор `URL` выбрасывает исключение для некорректной ссылки. Если ошибка разбора является ожидаемой,
используйте модуль [`РазборURL`](docs/РазборURL.md):

```bsl
#Использовать errors
#Использовать url

ВходнаяСтрока = "https://пример.рф/%";

Ошибка = Неопределено;
Адрес = РазборURL.ПопытатьсяРазобрать(ВходнаяСтрока, Ошибка);

Если Адрес = Неопределено Тогда
	Если ДиагностикаОшибок.КодОшибки(Ошибка) = КодыОшибокURL.НедопустимоеПроцентноеКодирование() Тогда
		Сообщить("Некорректное процентное кодирование");
	Иначе
		Сообщить(ПодробноеПредставлениеОшибки(Ошибка));
	КонецЕсли;
Иначе
	Сообщить(Адрес.ВСтроку());
КонецЕсли;
```

`ПопытатьсяРазобрать()` возвращает объект `URL` или `Неопределено`, а в необязательный второй параметр записывает
информацию об ошибке. Для простой проверки без получения объекта используйте `РазборURL.ЭтоКорректнаяСсылка()`.

## Сравнение и проверка схемы

```bsl
#Использовать url

Первая = Новый URL("HTTP://Example.COM/a%2f");
Вторая = Новый URL("http://example.com/a%2F");

Сообщить(Первая.РавенПоКомпонентам(Вторая));  // Истина
Сообщить(Первая.Сравнить(Вторая));            // 0

Адрес = Новый URL("http:/path");
Сообщить(Адрес.СоответствуетСхеме()); // Ложь: для HTTP нужен хост
```

Подробнее о лексическом, компонентном и нормализованном сравнении смотрите в
[документации URL](docs/URL.md#равен).

## Unicode и IDN

```bsl
#Использовать url

Адрес = Новый URL("https://пример.рф/путь?q=я");

Сообщить(Адрес.ВСтроку());
Сообщить(Адрес.IDNХост());
Сообщить(Адрес.КодированноеПредставление());
```

Результат:

```text
https://пример.рф/путь?q=я
xn--e1afmkfd.xn--p1ai
https://%D0%BF%D1%80%D0%B8%D0%BC%D0%B5%D1%80.%D1%80%D1%84/%D0%BF%D1%83%D1%82%D1%8C?q=%D1%8F
```

`ВСтроку()` сохраняет символы Unicode, `IDNХост()` преобразует доменное имя в Punycode, а
`КодированноеПредставление()` возвращает URI из символов ASCII с процентным кодированием UTF-8.

## Ошибки и границы ответственности

Ошибки в синтаксисе, процентном кодировании и хостах, а также несовместимые компоненты приводят к исключениям со
стабильными кодами, например `url.invalid_syntax` и `url.incompatible_components`. Получить и сопоставить коды
можно через модули [`КодыОшибокURL`](docs/КодыОшибокURL.md) и
[`ДиагностикаОшибок`](https://github.com/Stivo182/oscript-errors/blob/main/docs/ДиагностикаОшибок.md).

`url` работает только с текстовым представлением адресов: не выполняет DNS-запросы, HTTP-запросы и другие сетевые
операции. Библиотека не реализует браузерный алгоритм разбора WHATWG URL; из этого стандарта используется только
формат `application/x-www-form-urlencoded` для параметров запроса.
