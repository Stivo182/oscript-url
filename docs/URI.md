# URI

Неизменяемая URI-ссылка по [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html). Объект сохраняет исходное
написание компонентов, строго проверяет синтаксис и не выполняет сетевых операций. Все преобразования возвращают
новый объект и не изменяют исходный.

## Создание

```bsl
Новый URI(<Значение>)
```

Полная диспетчеризация конструктора:

| `Значение` | Поведение |
| --- | --- |
| `Строка` | Строгий разбор URI-ссылки с сохранением исходного написания |
| [`URI`](URI.md) | Создание независимой логически равной копии |
| [`URL`](URL.md) | Неизменяемый снимок текущего URL |
| Любой другой тип | `argument.invalid_type` |

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, [`URI`](URI.md), [`URL`](URL.md) | URI-ссылка или объект для копирования |

Конструктор возвращает новый [`URI`](URI.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |
| `uri.invalid_syntax` | Нарушена общая грамматика URI |
| `uri.invalid_scheme` | Недопустима схема |
| `uri.invalid_percent_encoding` | Нарушена форма `%HH` |
| `uri.invalid_authority` | Некорректна серверная часть |
| `uri.invalid_host` | Некорректен хост |
| `uri.invalid_ipv6` | Некорректен IPv6-адрес |
| `uri.invalid_ipvfuture` | Некорректен IPvFuture-адрес |

```bsl
Ссылка = Новый URI("../users?page=1");
Копия = Новый URI(Ссылка);
```

## Методы

### ВСтроку

Возвращает URI-ссылку в исходном написании без потерь.

```bsl
.ВСтроку()
```

#### Возвращаемое значение

`Строка`: исходное написание URI-ссылки.

### Схема

Возвращает схему в исходном регистре без завершающего `:`.

```bsl
.Схема()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если ссылка относительная.

### КодированнаяСервернаяЧасть

Возвращает серверную часть в исходном написании без начального `//`.

```bsl
.КодированнаяСервернаяЧасть()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если серверная часть отсутствует.

### СервернаяЧастьОпределена

Проверяет наличие структурного разделителя `//`.

```bsl
.СервернаяЧастьОпределена()
```

#### Возвращаемое значение

`Булево`: `Истина`, если серверная часть определена, в том числе пустая.

### КодированныеДанныеПользователя

Возвращает кодированные данные пользователя без завершающего `@`.

```bsl
.КодированныеДанныеПользователя()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если данные пользователя отсутствуют.

### ДанныеПользователяОпределены

Проверяет наличие структурного разделителя `@`.

```bsl
.ДанныеПользователяОпределены()
```

#### Возвращаемое значение

`Булево`: `Истина`, если данные пользователя определены, в том числе пустой строкой.

### ДанныеПользователя

Строго декодирует данные пользователя как UTF-8 по
[RFC 3986 § 3.2.1](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.2.1).

```bsl
.ДанныеПользователя()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если данные пользователя отсутствуют.

#### Ошибки

| Код | Условие |
| --- | --- |
| `encoding.invalid` | Процентные байты не образуют корректную последовательность UTF-8 |

### КодированноеИмяПользователя

Возвращает кодированную часть данных пользователя до первого буквального `:`.

```bsl
.КодированноеИмяПользователя()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если данные пользователя отсутствуют.

### КодированныйПароль

### КодированныйХост

Возвращает кодированный хост. Квадратные скобки IP-литерала сохраняются.

```bsl
.КодированныйХост()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если серверная часть отсутствует.

### Хост

Возвращает логическое представление хоста по
[RFC 3986 § 3.2.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.2.2). Зарегистрированное имя строго
декодируется как UTF-8, а квадратные скобки IP-литерала сохраняются.

```bsl
.Хост()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если серверная часть отсутствует.

#### Ошибки

| Код | Условие |
| --- | --- |
| `encoding.invalid` | Процентные байты имени не образуют корректную последовательность UTF-8 |

Возвращает серверную часть с декодированными данными пользователя и хостом, без начального `//`.

```bsl
.СервернаяЧасть()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если серверная часть отсутствует.

#### Ошибки

| Код | Условие |
| --- | --- |
| `encoding.invalid` | Один из декодируемых компонентов содержит некорректный UTF-8 |

### ТекстПорта

Возвращает исходный текст порта без начального `:`.

```bsl
.ТекстПорта()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если разделитель порта отсутствует. Для пустого порта возвращается пустая строка.

### ПортУказан

Проверяет наличие разделителя `:` перед портом.

```bsl
.ПортУказан()
```

#### Возвращаемое значение

`Булево`: `Истина`, если порт указан, включая пустой порт.

### Порт

Возвращает числовое значение непустого порта. По
[RFC 3986 § 3.2.3](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.2.3) общий порт не ограничен значением
`65535`.

```bsl
.Порт()
```

#### Возвращаемое значение

`Число` или `Неопределено` для отсутствующего либо пустого порта.

#### Ошибки

| Код | Условие |
| --- | --- |
| `url.port.numeric_overflow` | Текст порта нельзя точно представить числом |

### СтандартныйПорт

Возвращает стандартный порт известной схемы без учёта регистра.

```bsl
.СтандартныйПорт()
```

#### Возвращаемое значение

`Число` или `Неопределено`, если схема неизвестна либо отсутствует.

### ИспользуетСтандартныйПорт

Проверяет, отсутствует ли порт, пуст ли он или равен стандартному порту схемы.

```bsl
.ИспользуетСтандартныйПорт()
```

#### Возвращаемое значение

`Булево`: `Истина`, если URI использует стандартный порт известной схемы.

### ЭффективныйПорт

Возвращает явно указанный непустой порт либо стандартный порт схемы.

```bsl
.ЭффективныйПорт()
```

#### Возвращаемое значение

`Число` или `Неопределено`, если схема неизвестна и явный непустой порт отсутствует.

#### Ошибки

| Код | Условие |
| --- | --- |
| `url.port.numeric_overflow` | Явный порт нельзя точно представить числом |

### Нормализованный

Возвращает новую URI-ссылку, нормализованную по
[RFC 3986 § 6.2.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-6.2.2). При нормализации к общему виду
приводятся процентные триплеты, регистр схемы и хоста, а также сегменты `.` и `..`.

```bsl
.Нормализованный()
```

#### Возвращаемое значение

Новый независимый [`URI`](URI.md).

### НормализованныйДляСхемы

Дополнительно применяет правила известной схемы. Для `http`, `https`, `ws`, `wss` и `ftp` удаляются пустые и
стандартные порты; для HTTP-подобных схем `http`, `https`, `ws` и `wss` пустой путь становится `/`.

```bsl
.НормализованныйДляСхемы()
```

#### Возвращаемое значение

Новый независимый [`URI`](URI.md).

### Разрешить

Разрешает URI-ссылку относительно текущего абсолютного URI по
[RFC 3986 § 5.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-5.2). Кодированные `%2E` и `%2E%2E` не
считаются сегментами `.` и `..`.

```bsl
.Разрешить(<Ссылка>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Ссылка | `Строка`, [`URI`](URI.md), [`URL`](URL.md) | Относительная или абсолютная URI-ссылка |

#### Возвращаемое значение

Новый независимый [`URI`](URI.md) с результатом разрешения.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип ссылки |
| `uri.base_not_absolute` | Текущий URI не является абсолютным |
| Коды разбора URI | Переданная строка имеет недопустимый синтаксис |

#### Пример

```bsl
База = Новый URI("https://example.com/api/v1/");
Результат = База.Разрешить("../users");
// https://example.com/api/users
```

### СделатьОтносительным

Строит детерминированную URI-ссылку на абсолютную цель относительно текущего URI. Каждый сокращённый вариант
проверяется обратным разрешением по RFC 3986 § 5.2.

```bsl
.СделатьОтносительным(<Цель>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Цель | `Строка`, [`URI`](URI.md), [`URL`](URL.md) | Абсолютная целевая URI-ссылка |

#### Возвращаемое значение

Новый независимый [`URI`](URI.md): относительная ссылка либо нормализованная абсолютная цель.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип цели |
| `argument.invalid_value` | Цель не является абсолютной |
| `uri.base_not_absolute` | Текущий URI не является абсолютным |
| Коды разбора URI | Переданная строка имеет недопустимый синтаксис |
