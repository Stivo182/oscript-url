# ПараметрыЗапросаURL

Упорядоченная коллекция пар параметров запроса. Коллекция поддерживает два формата разбора и сериализации:

- [`RFC3986()`](ФорматыПараметровЗапросаURL.md#rfc3986) используется по умолчанию, кодирует пробел как `%20`
  и воспринимает `+` буквально;
- [`ВебФорма()`](ФорматыПараметровЗапросаURL.md#вебформа) следует
  `application/x-www-form-urlencoded`, кодирует пробел как `+` и воспринимает `+` как пробел.

[RFC 3986 §3.4](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.4) определяет компонент запроса как
неиерархические данные, но не задаёт модель пар `имя=значение`. Профиль `RFC3986()` использует для каждого имени
и значения незарезервированный набор из
[RFC 3986 §2.3](https://www.rfc-editor.org/rfc/rfc3986.html#section-2.3):
`ALPHA / DIGIT / "-" / "." / "_" / "~"`.

## Создание

```bsl
Новый ПараметрыЗапросаURL(
    <СтрокаПараметров> = Неопределено,
    <Формат> = Неопределено
)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| СтрокаПараметров | `Строка`, `Неопределено` | Кодированная строка без `?` или отсутствие строки запроса |
| Формат | `Строка`, `Неопределено` | Значение из [ФорматыПараметровЗапросаURL](ФорматыПараметровЗапросаURL.md). По умолчанию `RFC3986()` |

`Неопределено` и `""` различаются. Первое значение означает отсутствие строки запроса, второе означает явно
заданную пустую строку запроса. Метод [`ВСтроку()`](#встроку) для обоих состояний возвращает `""`, а метод
[`КодированнаяСтрока()`](#кодированнаястрока) сохраняет различие.

Последовательность `%HH` определена в
[RFC 3986 §2.1](https://www.rfc-editor.org/rfc/rfc3986.html#section-2.1). Некорректный `%` принимается как
литеральный символ: исходная строка сохраняется, а в кодированном представлении `%` заменяется на `%25`.
Это не последовательность процентного кодирования по RFC 3986, а нестрогое поведение URL. Оно согласуется с
[моделью ошибок WHATWG URL](https://url.spec.whatwg.org/#validation-error), в которой ошибка проверки не обязана
прерывать разбор адреса.
При разборе пар некорректный UTF-8 заменяется символом `U+FFFD`.

### Исключения

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Строка параметров или формат имеет недопустимый тип |
| `argument.invalid_value` | Передан неизвестный формат |
| `url.invalid_syntax` | Строка содержит недопустимый символ компонента запроса |

## Форматы

| Символ | `RFC3986()` | `ВебФорма()` |
| --- | --- | --- |
| пробел | `%20` | `+` |
| `+` | `%2B` | `%2B` |
| `~` | `~` | `%7E` |
| `*` | `%2A` | `*` |

В формате `RFC3986()` пара без значения сохраняется как `flag`. В формате `ВебФорма()` каждая пара имеет
строковое значение, поэтому `flag` разбирается и сериализуется как `flag=`.

## Методы

### ВМассив

```bsl
.ВМассив()
```

Возвращает новый `Массив` структур `Имя, Значение`. Изменение результата не влияет на коллекцию.

### ВСтроку

```bsl
.ВСтроку(<Формат> = Неопределено)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Формат | `Строка`, `Неопределено` | Значение из [ФорматыПараметровЗапросаURL](ФорматыПараметровЗапросаURL.md). По умолчанию текущий формат |

#### Возвращаемое значение

Возвращает пары, сериализованные в текущем или явно указанном формате. Явный формат действует только на этот
вызов и не меняет текущий формат, пары, исходную кодированную строку или связанный URL.

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Формат имеет недопустимый тип |
| `argument.invalid_value` | Передан неизвестный формат |

### КодированнаяСтрока

```bsl
.КодированнаяСтрока()
```

Возвращает актуальное ASCII-представление строки без `?` либо `Неопределено`, если компонент запроса отсутствует.

### ИсходнаяСтрока

```bsl
.ИсходнаяСтрока()
```

Возвращает исходное представление строки без `?` либо `Неопределено`, если компонент запроса отсутствует. До
изменения пар сохраняет исходное написание Unicode и `%HH`. После изменения пар возвращает строку,
сериализованную в текущем формате.

### ТекущийФормат

```bsl
.ТекущийФормат()
```

#### Возвращаемое значение

`Строка`: текущее значение из
[ФорматыПараметровЗапросаURL](ФорматыПараметровЗапросаURL.md).

### РазобратьКак

```bsl
.РазобратьКак(<Формат>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Формат | `Строка` | Значение из [ФорматыПараметровЗапросаURL](ФорматыПараметровЗапросаURL.md) |

#### Возвращаемое значение

Тот же объект `ПараметрыЗапросаURL`.

#### Поведение

Повторно разбирает текущую непустую кодированную строку в указанном формате. Строка сохраняется без изменений,
а смысл пар может измениться. Например, `q=a+b` означает `a+b` в `RFC3986()` и `a b` в `ВебФорма()`.
Если формат недопустим, коллекция остаётся без изменений.

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Формат имеет недопустимый тип |
| `argument.invalid_value` | Формат неизвестен, строка отсутствует или пуста |

### УстановитьКодированнуюСтроку

```bsl
.УстановитьКодированнуюСтроку(<Значение>, <Формат> = Неопределено)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, `Неопределено` | Строка без `?` или признак удаления строки запроса |
| Формат | `Строка`, `Неопределено` | Значение из [ФорматыПараметровЗапросаURL](ФорматыПараметровЗапросаURL.md). По умолчанию текущий формат |

#### Возвращаемое значение

Тот же объект `ПараметрыЗапросаURL`.

#### Поведение

Заменяет строку и разбирает её в указанном формате. Если формат не передан, сохраняется текущий формат.
`Неопределено` удаляет строку запроса. Явный формат вместе с `Неопределено` выбирает формат будущих изменений,
не создавая пустую строку запроса.
Если строка или формат недопустимы, коллекция остаётся без изменений. Процент,
не образующий последовательность `%HH`, в кодированном представлении заменяется на `%25`.

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Значение или формат имеет недопустимый тип |
| `argument.invalid_value` | Передан неизвестный формат |
| `url.invalid_syntax` | Значение содержит недопустимый символ компонента запроса |

### Добавить

```bsl
.Добавить(<Имя>, <Значение> = Неопределено)
```

Добавляет пару в конец и возвращает тот же объект. Строки сохраняются, булевы значения, числа и даты преобразуются
через `XMLСтрока()`, остальные значения через `Строка()`. `Null` вызывает `argument.invalid_type`.

В `RFC3986()` значение `Неопределено` создаёт параметр без `=`, а в `ВебФорма()` нормализуется в пустую строку.
Пустое имя без значения недопустимо только в `RFC3986()`.

### Установить

```bsl
.Установить(<Имя>, <Значение> = Неопределено)
```

Заменяет первую пару с указанным именем, удаляет остальные пары с тем же именем или добавляет новую пару.
Правила значений совпадают с методом [`Добавить()`](#добавить).

### Получить

```bsl
.Получить(<Имя>)
```

Возвращает первое значение или `Неопределено`. Для различения отсутствующей пары и пары без значения используйте
[`Содержит()`](#содержит).

### ПолучитьВсе

```bsl
.ПолучитьВсе(<Имя>)
```

Возвращает новый `ФиксированныйМассив` всех значений с указанным именем в порядке коллекции.

### Содержит

```bsl
.Содержит(<Имя>)
```

Возвращает `Истина`, если коллекция содержит хотя бы одну пару с точным именем.

### Количество

```bsl
.Количество()
```

Возвращает число пар, включая пары с повторяющимися именами.

### Удалить

```bsl
.Удалить(<Имя>)
```

Удаляет все пары с указанным именем и возвращает тот же объект.

### Очистить

```bsl
.Очистить()
```

Удаляет все пары и компонент запроса, затем возвращает тот же объект.

### Сортировать

```bsl
.Сортировать()
```

Стабильно сортирует пары по именам в порядке кодовых единиц UTF-16 и возвращает тот же объект.

## Связь с URL

Повторные вызовы `URL.ПараметрыЗапроса()` возвращают одну и ту же коллекцию. Изменения коллекции становятся видны
в URL. Ранее полученная ссылка на коллекцию остаётся актуальной после изменения строки запроса через методы URL,
а её текущий формат сохраняется.

`URL.УстановитьПараметрыЗапроса()` копирует пары и текущий формат. Переданная коллекция остаётся независимой.

Формат следует за источником строки запроса при операциях, создающих URL:

- копирование и нормализация используют формат исходного URL;
- разрешение ссылки использует формат того URL, от которого результат наследует строку запроса;
- релятивизация использует формат целевого URL.

Формат не участвует в строковом равенстве или эквивалентности URL.

## Примеры

Формат по умолчанию:

```bsl
Параметры = Новый ПараметрыЗапросаURL;
Параметры.Установить("q", "hello world");

Сообщить(Параметры.ВСтроку());
// q=hello%20world
```

Разбор строки запроса как веб-формы:

```bsl
Адрес = Новый URL("https://example.com/?q=hello+world");

Адрес.ПараметрыЗапроса()
    .РазобратьКак(ФорматыПараметровЗапросаURL.ВебФорма())
    .Установить("page", 2);

Сообщить(Адрес.ВСтроку());
// https://example.com/?q=hello+world&page=2
```

Однократная сериализация в другом формате:

```bsl
СтрокаФормы = Параметры.ВСтроку(
    ФорматыПараметровЗапросаURL.ВебФорма()
);
```
