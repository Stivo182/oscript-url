# ПараметрыЗапросаURL

Упорядоченная коллекция пар «имя - значение» по алгоритму
[WHATWG `application/x-www-form-urlencoded`](https://url.spec.whatwg.org/#application-x-www-form-urlencoded).
Регистр имён учитывается, дубликаты и порядок сохраняются. Коллекция может быть самостоятельной или связанной с
запросом [`URL`](URL.md).

## Создание

```bsl
Новый ПараметрыЗапросаURL(<СтрокаПараметров> = "", <ВладелецURL> = Неопределено)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| СтрокаПараметров | `Строка` | Параметры без начального `?`; по умолчанию пустая строка |
| ВладелецURL | [`URL`](URL.md), `Неопределено` | URL, запрос которого является источником состояния |

Конструктор возвращает новый [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип параметра |

При разборе `+` заменяется пробелом, некорректный `%` сохраняется, а некорректные последовательности UTF-8
заменяются на `U+FFFD`. Части без `=` получают пустое значение, а пустые части между `&` пропускаются.

Если указан владелец, его текущий запрос является источником состояния. Переданная `СтрокаПараметров` не заменяет
запрос владельца. Обычный способ получить связанную коллекцию:

```bsl
Параметры = Адрес.ПараметрыЗапроса();
```

Самостоятельную коллекцию можно скопировать в URL методом
[`URL.УстановитьПараметрыЗапроса()`](URL.md#установитьпараметрызапроса).

## Методы

### ВМассив

Возвращает глубокие независимые копии пар.

```bsl
.ВМассив()
```

#### Возвращаемое значение

Новый `Массив` структур с полями `Имя` и `Значение`. Изменение массива и структур не влияет на коллекцию.

### ВСтроку

Сериализует коллекцию по алгоритму `application/x-www-form-urlencoded`.

```bsl
.ВСтроку()
```

#### Возвращаемое значение

`Строка` без начального `?`. Пробел кодируется как `+`, а остальные байты UTF-8 - по правилам формы.

#### Поведение

Чтение связанной коллекции не изменяет исходное написание запроса владельца.

### Добавить

Добавляет новую пару в конец коллекции.

```bsl
.Добавить(<Имя>, <Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |
| Значение | `Строка` | Значение параметра |

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя или значение не является строкой |

### Количество

Возвращает количество всех пар, включая пары с повторяющимся именем.

```bsl
.Количество()
```

#### Возвращаемое значение

`Число`: количество пар.

### Очистить

Удаляет все пары.

```bsl
.Очистить()
```

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md). У связанной коллекции компонент запроса
удаляется полностью.

### Получить

Возвращает значение первой пары с указанным именем.

```bsl
.Получить(<Имя>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |

#### Возвращаемое значение

`Строка` или `Неопределено`, если пары с таким именем нет.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой |

### ПолучитьВсе

Возвращает значения всех пар с указанным именем в порядке коллекции.

```bsl
.ПолучитьВсе(<Имя>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |

#### Возвращаемое значение

Новый `ФиксированныйМассив`. Если пары отсутствуют, массив пуст.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой |

### Содержит

Проверяет наличие хотя бы одной пары с точным именем.

```bsl
.Содержит(<Имя>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |

#### Возвращаемое значение

`Булево`: `Истина`, если параметр существует.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой |

### Сортировать

Стабильно сортирует пары по последовательностям кодовых единиц UTF-16 в именах.

```bsl
.Сортировать()
```

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md). Порядок пар с одинаковыми именами сохраняется.

#### Поведение

Сортировка связанной пустой коллекции полностью удаляет компонент запроса.

### Удалить

Удаляет все пары с указанным именем.

```bsl
.Удалить(<Имя>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой |

#### Поведение

Связанная коллекция обновляет запрос владельца, даже если указанное имя отсутствует.

### Установить

Заменяет значение первой пары и удаляет остальные пары с тем же именем. Если имя отсутствует, добавляет пару в
конец.

```bsl
.Установить(<Имя>, <Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |
| Значение | `Строка` | Новое значение |

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя или значение не является строкой |

## Пример

```bsl
Параметры = Новый ПараметрыЗапросаURL("a=1&a=2&q=hello+world");

Параметры
    .Установить("a", "3")
    .Добавить("include", "orders");

Сообщить(Параметры.ВСтроку());
// a=3&q=hello+world&include=orders
```
