# ПараметрыЗапросаURL

Упорядоченная коллекция параметров запроса. Строковые имена и значения кодируются по алгоритму
[WHATWG `application/x-www-form-urlencoded`](https://url.spec.whatwg.org/#application-x-www-form-urlencoded).
Параметр может не иметь значения и знака `=`. Регистр имён учитывается, дубликаты и порядок сохраняются. Коллекция
может быть самостоятельной или связанной с запросом [`URL`](URL.md).

## Создание

```bsl
Новый ПараметрыЗапросаURL(<СтрокаПараметров> = "", <ВладелецURL> = Неопределено)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| СтрокаПараметров | `Строка` | Параметры без начального `?`; по умолчанию пустая строка |
| ВладелецURL | [`URL`](URL.md), `Неопределено` | URL, запрос которого является источником состояния |

Конструктор возвращает новый [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип параметра |

При разборе `+` заменяется пробелом, некорректный `%` сохраняется, а некорректные последовательности UTF-8
заменяются на `U+FFFD`. Части без `=` получают значение `Неопределено`, а пустые части между `&` пропускаются.

Если указан владелец, его текущий запрос является источником состояния. Переданная `СтрокаПараметров` не заменяет
запрос владельца. Обычный способ получить связанную коллекцию:

```bsl
Параметры = Адрес.ПараметрыЗапроса();
```

Связанная коллекция является живым представлением, а не снимком. Перед каждым публичным вызовом она перечитывает
текущий запрос владельца. Поэтому сохранённая коллекция увидит прямое изменение URL и изменение через другую
связанную коллекцию. Изменяющий метод сразу записывает результат обратно в URL.

Чтение не меняет исходное написание запроса. Любое изменение сериализует весь запрос заново: пробелы становятся
`+`, отсутствие `=` сохраняется, а некорректные последовательности заменяются в соответствии с правилами разбора.

Самостоятельную коллекцию можно скопировать в URL методом
[`URL.УстановитьПараметрыЗапроса()`](URL.md#установитьпараметрызапроса).

## Методы

### ВМассив

Возвращает глубокие независимые копии пар.

```bsl
.ВМассив()
```

#### Возвращаемое значение

Новый `Массив` структур с полями `Имя` и `Значение`. Значение имеет тип `Строка` или `Неопределено`. Изменение
массива и структур не влияет на коллекцию.

### ВСтроку

Кодирует строковые имена и значения по алгоритму `application/x-www-form-urlencoded`. Для параметра без значения
выводит только имя без знака `=`.

```bsl
.ВСтроку()
```

#### Возвращаемое значение

`Строка` без начального `?`. Пробел кодируется как `+`, а остальные байты UTF-8 - по правилам формы.

#### Поведение

Чтение связанной коллекции не изменяет исходное написание запроса владельца.

### Добавить

Добавляет новую пару в конец коллекции.

```bsl
.Добавить(<Имя>, <Значение> = Неопределено)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |
| Значение | `Произвольный`, кроме `Null` | Значение параметра; по умолчанию `Неопределено` |

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой или значение равно `Null` |
| `argument.invalid_value` | Имя пустое, а значение равно `Неопределено` |

#### Преобразование значения

| Тип | Строковое представление |
| --- | --- |
| `Строка` | Без изменений |
| `Булево` | Результат `XMLСтрока()`: `true` или `false` |
| `Число` | Результат `XMLСтрока()`: без группировки разрядов, с точкой как знаком дробной части |
| `Дата` | Результат [`XMLСтрока()`](https://www.oscript.io/syntax/XmlGlobalFunctions), например `2026-09-06T12:34:56` |
| `Неопределено` | Параметр без значения и без знака `=`, например `flag` |
| Остальные типы | Результат `Строка()` |

`Null` не преобразуется и вызывает исключение. Для удаления параметра предназначен метод [`Удалить()`](#удалить).
Параметр без значения должен иметь непустое имя, так как безымянный параметр без значения неотличим от пустой
строки запроса.

[RFC 3986, раздел 3.4](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.4) допускает форму `flag` в компоненте
запроса, но не определяет модель пар и преобразование прикладных типов.

Пустая строка и `Неопределено` различаются:

```bsl
Параметры.Добавить("flag");     // flag
Параметры.Добавить("empty", ""); // empty=
```

Тип `Дата` не хранит часовой пояс, поэтому полученная строка не содержит `Z` или числовое смещение. Такая строка
не является полной отметкой времени по [RFC 3339, раздел 5.6](https://www.rfc-editor.org/rfc/rfc3339.html#section-5.6),
где смещение обязательно.

### Количество

Возвращает количество всех пар, включая пары с повторяющимся именем.

```bsl
.Количество()
```

#### Возвращаемое значение

`Число`: количество пар.

### Очистить

Удаляет все пары.

```bsl
.Очистить()
```

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md). У связанной коллекции компонент запроса
удаляется полностью.

### Получить

Возвращает значение первой пары с указанным именем.

```bsl
.Получить(<Имя>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |

#### Возвращаемое значение

`Строка` или `Неопределено`. Результат `Неопределено` означает, что пара не найдена либо параметр не имеет
значения. Эти случаи различаются методом [`Содержит()`](#содержит).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой |

### ПолучитьВсе

Возвращает значения всех пар с указанным именем в порядке коллекции.

```bsl
.ПолучитьВсе(<Имя>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |

#### Возвращаемое значение

Новый `ФиксированныйМассив` строковых и неопределенных значений. Если пары отсутствуют, массив пуст.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой |

### Содержит

Проверяет наличие хотя бы одной пары с точным именем.

```bsl
.Содержит(<Имя>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |

#### Возвращаемое значение

`Булево`: `Истина`, если параметр существует.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой |

### Сортировать

Стабильно сортирует пары по последовательностям кодовых единиц UTF-16 в именах.

```bsl
.Сортировать()
```

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md). Порядок пар с одинаковыми именами сохраняется.

#### Поведение

Сортировка связанной пустой коллекции полностью удаляет компонент запроса.

### Удалить

Удаляет все пары с указанным именем.

```bsl
.Удалить(<Имя>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой |

#### Поведение

Связанная коллекция обновляет запрос владельца, даже если указанное имя отсутствует.

### Установить

Заменяет значение первой пары и удаляет остальные пары с тем же именем. Если имя отсутствует, добавляет пару в
конец.

```bsl
.Установить(<Имя>, <Значение> = Неопределено)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Имя параметра |
| Значение | `Произвольный`, кроме `Null` | Новое значение; по умолчанию `Неопределено` |

#### Возвращаемое значение

Тот же объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Имя не является строкой или значение равно `Null` |
| `argument.invalid_value` | Имя пустое, а значение равно `Неопределено` |

Значение преобразуется по тем же [правилам](#преобразование-значения), что и в методе `Добавить()`.

## Примеры

```bsl
#Использовать url

Параметры = Новый ПараметрыЗапросаURL("a=1&a=2&q=hello+world");

Параметры
    .Установить("a", 3)
    .Добавить("include", "orders")
    .Добавить("active", Истина)
    .Добавить("isValid");

Сообщить(Параметры.ВСтроку());
// a=3&q=hello+world&include=orders&active=true&isValid
```

Синхронизация связанных коллекций и пересериализация запроса:

```bsl
#Использовать url

Адрес = Новый URL("https://example.com/?a=hello%20world&flag");
ПервыеПараметры = Адрес.ПараметрыЗапроса();
ВторыеПараметры = Адрес.ПараметрыЗапроса();

ПервыеПараметры.Добавить("b", "2");
Сообщить(ВторыеПараметры.Получить("b"));
// 2

Сообщить(Адрес.ВСтроку());
// https://example.com/?a=hello+world&flag&b=2

Адрес.УстановитьКодированнуюСтрокуЗапроса("c=3");
Сообщить(ПервыеПараметры.Получить("c"));
// 3
```
