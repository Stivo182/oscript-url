# КодыОшибокURL

Публичный модуль предоставляет стабильные машинные коды предметных ошибок пакета `url`. Все функции чисты,
вызываются без параметров, возвращают значения типа `Строка` и не создают исключений.

## Подключение

[`КодыОшибокURL`](КодыОшибокURL.md) - общий модуль, поэтому его не создают оператором `Новый`:

```bsl
#Использовать url

Код = КодыОшибокURL.НедопустимыйСинтаксис();
```

## Функции

### БазаНеАбсолютная

```bsl
КодыОшибокURL.БазаНеАбсолютная()
```

#### Возвращаемое значение

`Строка` со значением `"url.base_not_absolute"`: операция требует абсолютную базовую URL-ссылку.

### НедопустимаяСервернаяЧасть

```bsl
КодыОшибокURL.НедопустимаяСервернаяЧасть()
```

#### Возвращаемое значение

`Строка` со значением `"url.invalid_authority"`: нарушена структура серверной части.

### НедопустимаяСхема

```bsl
КодыОшибокURL.НедопустимаяСхема()
```

#### Возвращаемое значение

`Строка` со значением `"url.invalid_scheme"`: нарушена грамматика схемы.

### НедопустимоеПроцентноеКодирование

```bsl
КодыОшибокURL.НедопустимоеПроцентноеКодирование()
```

#### Возвращаемое значение

`Строка` со значением `"url.invalid_percent_encoding"`: нарушена форма `%HH` по
[RFC 3986 § 2.1](https://www.rfc-editor.org/rfc/rfc3986.html#section-2.1).

### НедопустимыеДанныеIDNA

```bsl
КодыОшибокURL.НедопустимыеДанныеIDNA()
```

#### Возвращаемое значение

`Строка` со значением `"idna.data.invalid"`: контейнер нормативных данных IDNA отсутствует, недоступен
или повреждён. Для ошибок файловой системы исходная ошибка сохраняется в качестве причины.

### НедопустимыйДляСхемы

```bsl
КодыОшибокURL.НедопустимыйДляСхемы()
```

#### Возвращаемое значение

`Строка` со значением `"url.invalid_for_scheme"`: URI нарушает дополнительные ограничения известной схемы.

### НедопустимыйСинтаксис

```bsl
КодыОшибокURL.НедопустимыйСинтаксис()
```

#### Возвращаемое значение

`Строка` со значением `"url.invalid_syntax"`: нарушена общая грамматика URI.

### НедопустимыйХост

```bsl
КодыОшибокURL.НедопустимыйХост()
```

#### Возвращаемое значение

`Строка` со значением `"url.invalid_host"`: хост не соответствует допустимой форме.

### НесовместимыеКомпоненты

```bsl
КодыОшибокURL.НесовместимыеКомпоненты()
```

#### Возвращаемое значение

`Строка` со значением `"url.incompatible_components"`: серверная часть и путь нарушают совместные ограничения
[RFC 3986 § 3](https://www.rfc-editor.org/rfc/rfc3986.html#section-3).

### ПереполнениеЧисловогоПорта

```bsl
КодыОшибокURL.ПереполнениеЧисловогоПорта()
```

#### Возвращаемое значение

`Строка` со значением `"url.port.numeric_overflow"`: текст порта нельзя точно представить числом.

## Каталог кодов

| Функция | Значение |
| --- | --- |
| `НедопустимыйСинтаксис()` | `url.invalid_syntax` |
| `НедопустимаяСхема()` | `url.invalid_scheme` |
| `НедопустимоеПроцентноеКодирование()` | `url.invalid_percent_encoding` |
| `НедопустимаяСервернаяЧасть()` | `url.invalid_authority` |
| `НедопустимыйХост()` | `url.invalid_host` |
| `БазаНеАбсолютная()` | `url.base_not_absolute` |
| `НедопустимыйДляСхемы()` | `url.invalid_for_scheme` |
| `НесовместимыеКомпоненты()` | `url.incompatible_components` |
| `ПереполнениеЧисловогоПорта()` | `url.port.numeric_overflow` |
| `НедопустимыеДанныеIDNA()` | `idna.data.invalid` |

Ошибки типов и значений аргументов используют стандартные коды зависимости `errors`: `argument.invalid_type`,
`argument.required` и `argument.invalid_value`. Для некорректной последовательности UTF-8 используется код
`encoding.invalid`.

## Использование

```bsl
#Использовать errors
#Использовать url

Попытка
    Значение = Новый URL("https://example.com/%");
Исключение
    Код = ДиагностикаОшибок.КодОшибки(ИнформацияОбОшибке());

        Сообщить("Некорректный %HH");
    КонецЕсли;
КонецПопытки;
```
