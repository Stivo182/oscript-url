# КодыОшибокURL

Публичный модуль предоставляет стабильные машинные коды предметных ошибок пакета `url` без
строковых литералов в прикладном коде. Все функции вызываются без параметров и возвращают `Строка`.

## Использование

```bsl
#Использовать errors
#Использовать url

Попытка
    Значение = Новый URL("https://example.com/%");
Исключение
    Если ДиагностикаОшибок.Содержит(ИнформацияОбОшибке(), КодыОшибокURL.НедопустимоеПроцентноеКодирование()) Тогда
        Сообщить("Некорректный %HH");
    КонецЕсли;
КонецПопытки;
```

Для структурированного разбора `ИнформацияОбОшибке` используйте публичные средства пакета
`errors`; этот модуль отвечает только за именование предметных кодов.

## Каталог кодов

| Функция | Код | Описание |
| --- | --- | --- |
| `НедопустимыйСинтаксис()` | `url.invalid_syntax` | Нарушена общая грамматика URI |
| `НедопустимаяСхема()` | `url.invalid_scheme` | Нарушена грамматика схемы |
| `НедопустимоеПроцентноеКодирование()` | `url.invalid_percent_encoding` | Нарушена форма `%HH` |
| `НедопустимаяСервернаяЧасть()` | `url.invalid_authority` | Нарушена структура серверной части |
| `НедопустимыйХост()` | `url.invalid_host` | Хост не соответствует допустимой форме |
| `БазаНеАбсолютная()` | `url.base_not_absolute` | Требуется абсолютная базовая URL-ссылка |
| `НедопустимыйДляСхемы()` | `url.invalid_for_scheme` | Нарушены ограничения известной схемы |
| `НесовместимыеКомпоненты()` | `url.incompatible_components` | Несовместимы серверная часть и путь |
| `ПереполнениеЧисловогоПорта()` | `url.port.numeric_overflow` | Текст порта нельзя точно представить числом |
| `НедопустимыеДанныеIDNA()` | `idna.data.invalid` | Нормативные данные IDNA недоступны или повреждены |

Форма процентного кодирования определена в
[RFC 3986, раздел 2.1](https://www.rfc-editor.org/rfc/rfc3986.html#section-2.1). Ограничения на сочетание
серверной части и пути определены в
[RFC 3986, раздел 3](https://www.rfc-editor.org/rfc/rfc3986.html#section-3).

Для ошибок файловой системы при чтении нормативных данных IDNA исходная ошибка сохраняется в качестве причины.

Ошибки неправильных типов и значений аргументов используют стандартные коды зависимости
`errors`: `argument.invalid_type`, `argument.required` и `argument.invalid_value`. Для некорректной
последовательности UTF-8 используется код `encoding.invalid`; эти коды намеренно не дублируются этим модулем.
