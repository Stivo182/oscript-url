# КодыОшибокURL

Публичный модуль предоставляет стабильные машинные коды предметных ошибок пакета `url`. Все функции чисты,
вызываются без параметров, возвращают значения типа `Строка` и не создают исключений.

## Подключение

[`КодыОшибокURL`](КодыОшибокURL.md) - общий модуль, поэтому его не создают оператором `Новый`:

```bsl
#Использовать url

Код = КодыОшибокURL.НедопустимыйСинтаксисURI();
```

## Функции

### НедопустимыйСинтаксисURI

```bsl
КодыОшибокURL.НедопустимыйСинтаксисURI()
```

#### Возвращаемое значение

`Строка` со значением `"uri.invalid_syntax"`: нарушена общая грамматика URI.

### НедопустимаяСхемаURI

```bsl
КодыОшибокURL.НедопустимаяСхемаURI()
```

#### Возвращаемое значение

`Строка` со значением `"uri.invalid_scheme"`: нарушена грамматика схемы.

### НедопустимоеПроцентноеКодированиеURI

```bsl
КодыОшибокURL.НедопустимоеПроцентноеКодированиеURI()
```

#### Возвращаемое значение

`Строка` со значением `"uri.invalid_percent_encoding"`: нарушена форма `%HH` по
[RFC 3986 § 2.1](https://www.rfc-editor.org/rfc/rfc3986.html#section-2.1).

### НедопустимаяСервернаяЧастьURI

```bsl
КодыОшибокURL.НедопустимаяСервернаяЧастьURI()
```

#### Возвращаемое значение

`Строка` со значением `"uri.invalid_authority"`: нарушена структура серверной части.

### НедопустимыйХостURI

```bsl
КодыОшибокURL.НедопустимыйХостURI()
```

#### Возвращаемое значение

`Строка` со значением `"uri.invalid_host"`: хост не соответствует допустимой форме.

### НедопустимыйIPv6

```bsl
КодыОшибокURL.НедопустимыйIPv6()
```

#### Возвращаемое значение

`Строка` со значением `"uri.invalid_ipv6"`: нарушена форма IPv6-литерала из
[RFC 3986 § 3.2.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.2.2).

### НедопустимыйIPvFuture

```bsl
КодыОшибокURL.НедопустимыйIPvFuture()
```

#### Возвращаемое значение

`Строка` со значением `"uri.invalid_ipvfuture"`: нарушена форма IPvFuture-литерала из RFC 3986 § 3.2.2.

### БазаURIНеАбсолютная

```bsl
КодыОшибокURL.БазаURIНеАбсолютная()
```

#### Возвращаемое значение

`Строка` со значением `"uri.base_not_absolute"`: операция требует абсолютную базовую URI-ссылку.

### ОтносительныйURLБезБазы

```bsl
КодыОшибокURL.ОтносительныйURLБезБазы()
```

#### Возвращаемое значение

`Строка` со значением `"url.relative_without_base"`: относительный URL передан без абсолютной базы.

### БазаURLНеАбсолютная

```bsl
КодыОшибокURL.БазаURLНеАбсолютная()
```

#### Возвращаемое значение

`Строка` со значением `"url.base_not_absolute"`: база конструктора [`URL`](URL.md) не является абсолютной.

### НесовместимыеКомпонентыURL

```bsl
КодыОшибокURL.НесовместимыеКомпонентыURL()
```

#### Возвращаемое значение

`Строка` со значением `"url.incompatible_components"`: серверная часть и путь нарушают совместные ограничения
[RFC 3986 § 3](https://www.rfc-editor.org/rfc/rfc3986.html#section-3).

### НедопустимыйКомпонентURL

```bsl
КодыОшибокURL.НедопустимыйКомпонентURL()
```

#### Возвращаемое значение

`Строка` со значением `"url.invalid_component"`: значение компонента URL недопустимо.

#### Поведение

Код зарезервирован для совместимости. Текущие методы библиотеки его не создают.

### UnicodeХостНеПоддерживается

```bsl
КодыОшибокURL.UnicodeХостНеПоддерживается()
```

#### Возвращаемое значение

`Строка` со значением `"url.unsupported_unicode_host"`.

#### Поведение

Код зарезервирован для совместимости. Текущие методы библиотеки его не создают.

### ПереполнениеЧисловогоПорта

```bsl
КодыОшибокURL.ПереполнениеЧисловогоПорта()
```

#### Возвращаемое значение

`Строка` со значением `"url.port.numeric_overflow"`: текст порта нельзя точно представить числом.

## Каталог кодов

| Функция | Значение |
| --- | --- |
| `НедопустимыйСинтаксисURI()` | `uri.invalid_syntax` |
| `НедопустимаяСхемаURI()` | `uri.invalid_scheme` |
| `НедопустимоеПроцентноеКодированиеURI()` | `uri.invalid_percent_encoding` |
| `НедопустимаяСервернаяЧастьURI()` | `uri.invalid_authority` |
| `НедопустимыйХостURI()` | `uri.invalid_host` |
| `НедопустимыйIPv6()` | `uri.invalid_ipv6` |
| `НедопустимыйIPvFuture()` | `uri.invalid_ipvfuture` |
| `БазаURIНеАбсолютная()` | `uri.base_not_absolute` |
| `ОтносительныйURLБезБазы()` | `url.relative_without_base` |
| `БазаURLНеАбсолютная()` | `url.base_not_absolute` |
| `НесовместимыеКомпонентыURL()` | `url.incompatible_components` |
| `НедопустимыйКомпонентURL()` | `url.invalid_component` |
| `UnicodeХостНеПоддерживается()` | `url.unsupported_unicode_host` |
| `ПереполнениеЧисловогоПорта()` | `url.port.numeric_overflow` |

Ошибки типов и значений аргументов используют стандартные коды зависимости `errors`: `argument.invalid_type`,
`argument.required` и `argument.invalid_value`. Для некорректной последовательности UTF-8 используется код
`encoding.invalid`.

## Использование

```bsl
#Использовать errors
#Использовать url

Попытка
    Значение = Новый URI("https://example.com/%");
Исключение
    Код = ДиагностикаОшибок.КодОшибки(ИнформацияОбОшибке());
    Если Код = КодыОшибокURL.НедопустимоеПроцентноеКодированиеURI() Тогда
        Сообщить("Некорректный %HH");
    КонецЕсли;
КонецПопытки;
```
