# ШаблонURI

Класс раскрывает шаблоны URI по
[RFC 6570](https://www.rfc-editor.org/rfc/rfc6570.html) и возвращает новый объект [`URL`](URL.md).
Поддерживаются все четыре уровня стандарта.
Шаблон описывает построение ссылки, но не предназначен для разбора готового адреса.
Грамматика литералов учитывает проверенное
[исправление RFC 6570 Errata 6937](https://www.rfc-editor.org/errata/eid6937).

## Быстрый старт

```bsl
#Использовать url

Шаблон = Новый ШаблонURI(
    "https://api.example.com/users/{id}{?page,filter}"
);

Значения = Новый Соответствие;
Значения.Вставить("id", "Иван/42");
Значения.Вставить("page", 2);
Значения.Вставить("filter", "active users");

Адрес = Шаблон.Раскрыть(Значения);
Сообщить(Адрес.КодированноеПредставление());
```

Результат:

```text
https://api.example.com/users/%D0%98%D0%B2%D0%B0%D0%BD%2F42?page=2&filter=active%20users
```

## Конструктор

```bsl
Новый ШаблонURI(Представление)
```

`Представление` должно быть строкой с шаблоном URI по RFC 6570. Конструктор сразу проверяет
грамматику и сохраняет разобранное представление для повторного использования. Пустая строка
является допустимым шаблоном.

Исключения:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Представление не является строкой |
| `url.template.invalid_syntax.*` | Нарушена грамматика шаблона URI |

## Раскрыть

```bsl
.Раскрыть(Значения = Неопределено)
```

Возвращает новый `URL`. Значения передаются по именам через `Соответствие`,
`ФиксированноеСоответствие`, `Структура` или `ФиксированнаяСтруктура`. Отсутствующее значение,
`Неопределено` и `Null` означают неопределённую переменную и не добавляются в результат.

Переданная коллекция и входящие в неё составные значения не должны изменяться до завершения
вызова. Один шаблон можно одновременно раскрывать с отдельными или неизменяемыми коллекциями.

## ИменаПеременных

```bsl
.ИменаПеременных()
```

Возвращает новый изменяемый `Массив` уникальных имён в порядке первого появления.
Имена чувствительны к регистру. Процентные последовательности в имени не декодируются.

## ВСтроку

```bsl
.ВСтроку()
```

Возвращает исходное представление шаблона без нормализации и раскрытия.

## Операторы

| Выражение | Назначение | Пример результата |
| --- | --- | --- |
| `{var}` | Простое значение | `value` |
| `{+var}` | Значение с зарезервированными символами | `/foo/bar` |
| `{#var}` | Фрагмент | `#value` |
| `{.var}` | Метка с точкой | `.value` |
| `{/var}` | Сегмент пути | `/value` |
| `{;var}` | Параметр пути | `;var=value` |
| `{?var}` | Начало запроса | `?var=value` |
| `{&var}` | Продолжение запроса | `&var=value` |

Операторы `+` и `#` сохраняют зарезервированные символы и корректные последовательности `%HH`.
Остальные операторы оставляют без кодирования только незарезервированные символы URI.
Пробел всегда кодируется как `%20`.

Пример с путем, запросом и фрагментом:

```bsl
Значения = Новый Структура;
Значения.Вставить("path", "/catalog/items");
Значения.Вставить("id", "Иван/42");
Значения.Вставить("q", "active users");
Значения.Вставить("page", 2);
Значения.Вставить("anchor", "part 1");

Сообщить(Новый ШаблонURI("{+path}").Раскрыть(Значения).КодированноеПредставление());
// /catalog/items

Сообщить(Новый ШаблонURI("{/id}").Раскрыть(Значения).КодированноеПредставление());
// /%D0%98%D0%B2%D0%B0%D0%BD%2F42

Сообщить(Новый ШаблонURI("{?q,page}").Раскрыть(Значения).КодированноеПредставление());
// ?q=active%20users&page=2

Сообщить(Новый ШаблонURI("section{#anchor}").Раскрыть(Значения).КодированноеПредставление());
// section#part%201
```

## Значения

| Вид | Типы OneScript |
| --- | --- |
| Простое значение | `Строка`, `Число`, `Булево`, `Дата` |
| Список | `Массив`, `ФиксированныйМассив` |
| Ассоциативное значение | Соответствие или структура, включая фиксированные виды |

Числа, булевы значения и даты преобразуются функцией `XMLСтрока()`. Вложенные поля структур
раскрываются с составными именами через точку, как предписывает
[RFC 6570 §2.4.2](https://www.rfc-editor.org/rfc/rfc6570.html#section-2.4.2). Вложенные списки
и соответствия не поддерживаются. Неопределённые элементы списка, поля структуры и пары
соответствия пропускаются. Пустое составное значение считается неопределённой переменной.

Строки Unicode не нормализуются автоматически. Для пользовательского ввода рекомендуется заранее
применять NFC, как указано в
[RFC 6570 §1.6](https://www.rfc-editor.org/rfc/rfc6570.html#section-1.6). Значения из источников,
где форма нормализации уже определена протоколом, передаются без изменения кодовых точек.

```bsl
Список = Новый Массив;
Список.Добавить("red");
Список.Добавить("green");

Значения = Новый Соответствие;
Значения.Вставить("colors", Список);

Адрес = Новый ШаблонURI("{/colors*}").Раскрыть(Значения);
Сообщить(Адрес.КодированноеПредставление()); // /red/green
```

Без `*` тот же список объединяется запятыми:

```bsl
Адрес = Новый ШаблонURI("{?colors}").Раскрыть(Значения);
Сообщить(Адрес.КодированноеПредставление()); // ?colors=red,green
```

Ассоциативное значение можно развернуть в отдельные параметры запроса:

```bsl
Фильтр = Новый Соответствие;
Фильтр.Вставить("status", "active");
Фильтр.Вставить("role", "site admin");

Значения = Новый Соответствие;
Значения.Вставить("filter", Фильтр);

Адрес = Новый ШаблонURI("/users{?filter*}").Раскрыть(Значения);
Сообщить(Адрес.КодированноеПредставление());
// /users?status=active&role=site%20admin
```

Вложенные структуры разворачиваются в глубину, а части имени поля разделяются точками:

```bsl
Контакты = Новый Структура("email", "ivan@example.com");
Профиль = Новый Структура("name,contact", "Ivan", Контакты);

Значения = Новый Соответствие;
Значения.Вставить("profile", Профиль);

Адрес = Новый ШаблонURI("/users{?profile*}").Раскрыть(Значения);
Сообщить(Адрес.КодированноеПредставление());
// /users?name=Ivan&contact.email=ivan%40example.com
```

Отсутствующая переменная не оставляет разделитель:

```bsl
Значения = Новый Структура("page", 2);

Адрес = Новый ШаблонURI("/users{?filter,page}").Раскрыть(Значения);
Сообщить(Адрес.КодированноеПредставление()); // /users?page=2
```

## Модификаторы

`*` разворачивает список или ассоциативное значение по членам:

Для пустого значения ассоциативной пары знак `=` опускается у всех операторов, кроме `?` и `&`.

```bsl
Цвета = Новый Массив;
Цвета.Добавить("red");
Цвета.Добавить("green");

Значения = Новый Структура("colors", Цвета);

Обычный = Новый ШаблонURI("{?colors}").Раскрыть(Значения);
Сообщить(Обычный.КодированноеПредставление());
// ?colors=red,green

Развернутый = Новый ШаблонURI("{?colors*}").Раскрыть(Значения);
Сообщить(Развернутый.КодированноеПредставление());
// ?colors=red&colors=green
```

`:число` ограничивает простое значение указанным количеством кодовых точек Unicode:

```bsl
Значения = Новый Структура("name", "Иванов");

Адрес = Новый ШаблонURI("/users/{name:3}").Раскрыть(Значения);
Сообщить(Адрес.КодированноеПредставление());
// /users/%D0%98%D0%B2%D0%B0
```

Допустимы значения от `1` до `9999`. Модификатор не разрывает суррогатную пару или процентный
триплет. Последовательность триплетов, представляющая один символ UTF-8, учитывается как одна
кодовая точка. В остальных случаях каждый синтаксически корректный `%HH` учитывается отдельно.

## Ошибки

Код ошибки зависит от этапа, на котором обнаружена проблема:

| Этап | Код | Условие |
| --- | --- | --- |
| Создание шаблона | `argument.invalid_type` | Представление шаблона не является строкой |
| Разбор шаблона | `url.template.invalid_syntax.*` | Представление не соответствует грамматике RFC 6570 |
| Раскрытие | `argument.invalid_type` | Коллекция, ключ или значение имеет недопустимый тип |
| Раскрытие | `argument.invalid_value.*` | Составное значение имеет недопустимую форму |
| Создание результата | Код разбора URI | Раскрытая строка не является допустимой URI-ссылкой |

### Ошибка синтаксиса шаблона

`КодыОшибокURL.НедопустимыйСинтаксисШаблона()` возвращает группу
`url.template.invalid_syntax`. Последний сегмент полного кода уточняет нарушение грамматики.
Сообщение указывает позицию в кодовых точках Unicode и ожидаемую конструкцию:

```text
Недопустимый синтаксис шаблона URI в позиции 5 (ожидается: имя переменной)
```

В `Данные` передаются:

| Поле | Содержание |
| --- | --- |
| `Позиция` | Номер кодовой точки Unicode с единицы |
| `Ожидание` | Безопасное описание ожидаемой конструкции |

Возможные полные коды:

| Код | Условие |
| --- | --- |
| `url.template.invalid_syntax.invalid_character` | В шаблоне встретился недопустимый символ |
| `url.template.invalid_syntax.invalid_percent_encoding` | Последовательность `%HH` записана неверно |
| `url.template.invalid_syntax.unclosed_expression` | Для открывающей `{` отсутствует закрывающая `}` |
| `url.template.invalid_syntax.empty_expression` | Выражение не содержит имени переменной |
| `url.template.invalid_syntax.unsupported_operator` | Использован зарезервированный оператор |
| `url.template.invalid_syntax.invalid_variable` | Имя переменной нарушает грамматику RFC 6570 |
| `url.template.invalid_syntax.invalid_modifier` | Модификатор `*` или `:число` записан неверно |

Для обработки всех нарушений грамматики используйте
`ДиагностикаОшибок.СодержитГруппу(Ошибка, "url.template.invalid_syntax")`.

### Ошибки значений

Недопустимый тип коллекции, ключа или значения приводит к `argument.invalid_type`.
Группа `argument.invalid_value` используется для нарушений ограничений значений:

| Код | Условие |
| --- | --- |
| `argument.invalid_value.nested_composite` | Список или соответствие вложено в составное значение |
| `argument.invalid_value.prefix_for_composite` | Модификатор `:число` применён к составному значению |
| `argument.invalid_value.invalid_unicode` | Строка содержит некорректную последовательность UTF-16 |
| `argument.invalid_value.cyclic_structure` | Вложенная структура содержит циклическую ссылку |

Сообщение содержит имя переменной и нарушенное ограничение:

```text
Недопустимое значение переменной шаблона URI "list": вложенные списки и соответствия не поддерживаются
```

В `Данные` передаются:

| Поле | Содержание |
| --- | --- |
| `ИмяПеременной` | Имя переменной шаблона, значение которой вызвало ошибку |
| `Ожидание` | Безопасное описание допустимого значения или ограничения |

Для обработки всех этих ошибок используйте
`ДиагностикаОшибок.СодержитГруппу(Ошибка, "argument.invalid_value")`.

### Ошибки итоговой URI-ссылки

После раскрытия строка передаётся конструктору `URL`. Если она нарушает общую грамматику URI,
`Раскрыть()` сохраняет исходный код ошибки: `url.invalid_syntax`, `url.invalid_scheme`,
`url.invalid_percent_encoding`, `url.invalid_authority` или `url.invalid_host`. Условия этих ошибок
описаны в разделе [кодов разбора URI](КодыОшибокURL.md#коды-разбора-uri).

Исходный шаблон и значения переменных не включаются ни в сообщение, ни в `Данные` ошибки.

## Безопасность

Раскрытие не выполняет сетевой запрос и не проверяет назначение ссылки. Операторы `+` и `#`
могут сохранить символы, меняющие границы компонентов URI. Перед сетевым обращением вызывающий
код должен проверить схему, хост и предметные ограничения результата.

Подробнее: [RFC 6570 §4](https://www.rfc-editor.org/rfc/rfc6570.html#section-4).
