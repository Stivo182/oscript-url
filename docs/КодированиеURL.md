# КодированиеURL

Публичный модуль кодирует компоненты URI и параметры формы. Функции не изменяют входные строки и не выполняют
сетевых операций.

## Подключение

[`КодированиеURL`](КодированиеURL.md) - общий модуль, поэтому его не создают оператором `Новый`:

```bsl
#Использовать url

Путь = КодированиеURL.КодироватьПуть("/Иван Петров");
```

## Функции

### ДекодироватьВБайты

Строго декодирует процентные триплеты ASCII-строки в последовательность байтов.

```bsl
КодированиеURL.ДекодироватьВБайты(<Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | ASCII-строка с процентным кодированием |

#### Возвращаемое значение

Новый объект `ДвоичныеДанные` с декодированными байтами.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |
| `argument.invalid_value` | Строка содержит символы вне ASCII |
| `url.invalid_percent_encoding` | Нарушена форма `%HH` |

### ДекодироватьПараметрФормы

Нестрого декодирует значение `application/x-www-form-urlencoded`: `+` становится пробелом, некорректный `%`
сохраняется, а некорректные последовательности UTF-8 заменяются на `U+FFFD`.

```bsl
КодированиеURL.ДекодироватьПараметрФормы(<Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Декодируемое значение формы |

#### Возвращаемое значение

`Строка` с декодированным значением.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |

### ДекодироватьUTF8

Строго декодирует процентные триплеты ASCII-строки, а затем декодирует полученные байты как UTF-8.

```bsl
КодированиеURL.ДекодироватьUTF8(<Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | ASCII-строка с процентным кодированием |

#### Возвращаемое значение

`Строка`, декодированная из UTF-8.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |
| `argument.invalid_value` | Строка содержит символы вне ASCII |
| `url.invalid_percent_encoding` | Нарушена форма `%HH` |
| `encoding.invalid` | Байты не образуют корректную последовательность UTF-8 |

### КодироватьДанныеПользователя

Кодирует полные данные пользователя по
[RFC 3986 § 3.2.1](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.2.1). Буквальный `:` сохраняется как
разделитель имени и пароля.

```bsl
КодированиеURL.КодироватьДанныеПользователя(<Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Кодируемые данные пользователя |

#### Возвращаемое значение

`Строка` с процентным кодированием байтов UTF-8.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |

### КодироватьПараметрФормы


| Параметр | Тип | Описание |
| --- | --- | --- |

#### Возвращаемое значение

`Строка` в представлении `application/x-www-form-urlencoded`.
