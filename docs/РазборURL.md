# РазборURL

Публичный модуль разбирает URI-ссылки без передачи исключений вызывающему коду. Использует ту же
общую грамматику, что и конструктор [`URL`](URL.md), по
[RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html) и [RFC 3987](https://www.rfc-editor.org/rfc/rfc3987.html).

Успешный разбор не проверяет ограничения конкретной схемы, доверие к узлу или его сетевую доступность.
Для `http`, `https`, `ws`, `wss` и `ftp` дополнительно вызывайте
[`URL.СоответствуетСхеме()`](URL.md#соответствуетсхеме).

## ПопытатьсяРазобрать

```bsl
РазборURL.ПопытатьсяРазобрать(<Значение>, <Ошибка> = Неопределено)
```

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Разбираемая URI-ссылка |
| Ошибка | `ИнформацияОбОшибке`, `Неопределено` | Выходной параметр с ошибкой |

### Возвращаемое значение

Новый [`URL`](URL.md) или `Неопределено`, если конструктор завершился ошибкой. Во втором случае параметр `Ошибка`
содержит причину. Возможные предметные коды перечислены в разделе
[«Коды разбора URI»](КодыОшибокURL.md#коды-разбора-uri).

### Пример

```bsl
#Использовать url

Ошибка = Неопределено;
Ссылка = РазборURL.ПопытатьсяРазобрать("https://example.com/%", Ошибка);
```

Модуль перехватывает любое исключение конструктора, поэтому причину следует определять по параметру `Ошибка`.

## ЭтоКорректнаяСсылка

```bsl
РазборURL.ЭтоКорректнаяСсылка(<Значение>)
```

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Проверяемая URI-ссылка |

### Возвращаемое значение

`Булево`: `Истина`, если `ПопытатьсяРазобрать()` вернул объект `URL`. При любом перехваченном исключении возвращает
`Ложь`. Если нужна причина ошибки, используйте `ПопытатьсяРазобрать()`.

### Пример

```bsl
#Использовать url

Корректна = РазборURL.ЭтоКорректнаяСсылка("https://example.com/path");
```
