# РазборURL

Публичный модуль разбирает URI-ссылки и серверные адреса. Использует ту же общую грамматику, что и конструктор
[`URL`](URL.md), по
[RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html) и [RFC 3987](https://www.rfc-editor.org/rfc/rfc3987.html).

`ПопытатьсяРазобрать()` и `ЭтоКорректнаяСсылка()` не проверяют ограничения конкретной схемы. Для `http`, `https`,
`ws`, `wss` и `ftp` после них дополнительно вызывайте [`URL.СоответствуетСхеме()`](URL.md#соответствуетсхеме).
`РазобратьСоСхемойПоУмолчанию()` и `ПопытатьсяРазобратьСоСхемойПоУмолчанию()` выполняют проверку автоматически.
Ни одна операция модуля не проверяет доверие к узлу или его сетевую доступность.

## ПопытатьсяРазобрать

```bsl
РазборURL.ПопытатьсяРазобрать(<Значение>, <Ошибка> = Неопределено)
```

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Разбираемая URI-ссылка |
| Ошибка | `ИнформацияОбОшибке`, `Неопределено` | Выходной параметр с ошибкой |

### Возвращаемое значение

Новый [`URL`](URL.md) или `Неопределено`, если конструктор завершился ошибкой. Во втором случае параметр `Ошибка`
содержит причину. Возможные предметные коды перечислены в разделе
[«Коды разбора URI»](КодыОшибокURL.md#коды-разбора-uri).

### Пример

```bsl
#Использовать url

Ошибка = Неопределено;
Ссылка = РазборURL.ПопытатьсяРазобрать("https://example.com/%", Ошибка);
```

Модуль перехватывает любое исключение конструктора, поэтому причину следует определять по параметру `Ошибка`.

## РазобратьСоСхемойПоУмолчанию

```bsl
РазборURL.РазобратьСоСхемойПоУмолчанию(<Значение>, <СхемаПоУмолчанию>)
```

Разбирает серверный адрес с необязательной схемой. Если схема в адресе отсутствует, добавляет переданную схему.
Явно заданную схему сохраняет. Операция предназначена для серверных адресов, а не для произвольных относительных
URI-ссылок.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Серверный адрес или абсолютный иерархический URL |
| СхемаПоУмолчанию | `Строка` | Схема без завершающего двоеточия, применяемая при отсутствии явной |

### Возвращаемое значение

Новый независимый [`URL`](URL.md) с определённой серверной частью и непустым хостом.

### Исключения

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Значение или схема по умолчанию имеют тип, отличный от `Строка` |
| `argument.required` | Значение или схема по умолчанию не заполнены |
| `url.invalid_scheme` | Схема не соответствует грамматике RFC 3986 |
| `url.server_address_required` | Значение не имеет поддерживаемой формы серверного адреса |
| Коды разбора URI | Сформированный URL нарушает общую грамматику |
| `url.invalid_for_scheme` | URL нарушает ограничения известной сетевой схемы |

Грамматика схемы определена в
[RFC 3986, раздел 3.1](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.1).

Для `url.server_address_required` исходная строка не включается в текст и данные ошибки. Это защищает пароль из
данных пользователя от случайного вывода в журнал.

### Пример

```bsl
#Использовать url

Адрес = РазборURL.РазобратьСоСхемойПоУмолчанию("hub.example/private", "https");
Сообщить(Адрес.ВСтроку()); // https://hub.example/private
```

Сетевые ссылки вида `//hub.example/private` и абсолютные иерархические URL также поддерживаются. Согласно
[RFC 3986, раздел 4.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-4.2), строка
`hub.example/private` сама по себе является относительным путём. Именно поэтому для неё нужна отдельная операция.

## ПопытатьсяРазобратьСоСхемойПоУмолчанию

```bsl
РазборURL.ПопытатьсяРазобратьСоСхемойПоУмолчанию(<Значение>, <СхемаПоУмолчанию>, <Ошибка> = Неопределено)
```

Разбирает те же формы серверного адреса, что и `РазобратьСоСхемойПоУмолчанию()`, но не выбрасывает исключения.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Серверный адрес или абсолютный иерархический URL |
| СхемаПоУмолчанию | `Строка` | Схема без завершающего двоеточия, применяемая при отсутствии явной |
| Ошибка | `ИнформацияОбОшибке`, `Неопределено` | Выходной параметр с ошибкой |

### Возвращаемое значение

Новый независимый [`URL`](URL.md) или `Неопределено` при ошибке. При успехе параметр `Ошибка` получает значение
`Неопределено`. При ошибке он содержит её причину с тем же предметным кодом, который выбрасывает
`РазобратьСоСхемойПоУмолчанию()`.

### Пример

```bsl
#Использовать url

Ошибка = Неопределено;
Адрес = РазборURL.ПопытатьсяРазобратьСоСхемойПоУмолчанию("hub.example/private", "https", Ошибка);
```


## ЭтоКорректнаяСсылка

```bsl
РазборURL.ЭтоКорректнаяСсылка(<Значение>)
```

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Проверяемая URI-ссылка |

### Возвращаемое значение

`Булево`: `Истина`, если `ПопытатьсяРазобрать()` вернул объект `URL`. При любом перехваченном исключении возвращает
`Ложь`. Если нужна причина ошибки, используйте `ПопытатьсяРазобрать()`.

### Пример

```bsl
#Использовать url

Корректна = РазборURL.ЭтоКорректнаяСсылка("https://example.com/path");
```
