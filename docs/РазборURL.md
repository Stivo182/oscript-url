# РазборURL

Публичный модуль для безопасного разбора URI-ссылок без исключения как обычного результата ошибки ввода.
Синтаксис проверяется тем же конструктором [`URL`](URL.md) по
[RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html) и
[RFC 3987](https://www.rfc-editor.org/rfc/rfc3987.html).

## Оглавление

- [ПопытатьсяРазобрать](#попытатьсяразобрать)
- [ЭтоКорректнаяСсылка](#этокорректнаяссылка)

## ПопытатьсяРазобрать

```bsl
Ошибка = Неопределено;
Ссылка = РазборURL.ПопытатьсяРазобрать(Значение, Ошибка);
```

Возвращает новый [`URL`](URL.md), если строка корректна, либо `Неопределено` при ошибке разбора или неправильном
типе аргумента. Необязательный выходной параметр `Ошибка` получает `ИнформацияОбОшибке` при любом исключении.
До разбора и после успешного разбора параметр содержит `Неопределено`. Исключения наружу не передаются.

## ЭтоКорректнаяСсылка

```bsl
Корректна = РазборURL.ЭтоКорректнаяСсылка(Значение);
```

Возвращает `Булево`: `Истина`, если `ПопытатьсяРазобрать()` вернул объект [`URL`](URL.md).
