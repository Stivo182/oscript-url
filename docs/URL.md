# URL

Изменяемая абсолютная или относительная URI-ссылка с символами Unicode на основе
[RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html) и
[RFC 3987](https://www.rfc-editor.org/rfc/rfc3987.html). Все изменения атомарны: при ошибке объект сохраняет
прежнее состояние. Компоненты, которых операция не касается, сохраняют исходное написание.

Имя класса `URL` используется как короткое предметное имя. Объект представляет URI-ссылку: она может быть
абсолютной или относительной.

## Основные понятия

Пример иерархической URI-ссылки с серверной частью:

```text
схема://данные-пользователя@хост:порт/путь?запрос#фрагмент
```

Серверная часть содержит только данные пользователя, хост и порт. Путь, запрос и фрагмент в неё не входят.

Абсолютная URI-ссылка содержит схему, например `urn:isbn:9780140328721` или `http:/path`. Относительная ссылка
схемы не содержит, например `../images/logo.svg`. Дополнительные требования `http`, `https`, `ws`, `wss` и `ftp`
проверяет отдельный метод [`СоответствуетСхеме()`](#соответствуетсхеме).

Для компонентов с процентным кодированием предусмотрены пары методов:

- метод со словом `Кодированный` возвращает или принимает исходное `%HH`;
- метод без слова `Кодированный` декодирует или кодирует значение как UTF-8.

Например, для пути `/files/a%2Fb` метод `КодированныйПуть()` вернёт `/files/a%2Fb`, а `Путь()` вернёт
`/files/a/b`. При этом `%2F` остаётся частью одного сегмента и не становится разделителем.

Если границы сегментов имеют значение для маршрутизации или проверки безопасности, используйте
`СегментыПути()` или `КодированныеСегментыПути()`. Не разделяйте результат `Путь()` по символу `/`: после
декодирования нельзя отличить исходный разделитель от `%2F` внутри сегмента.

`УстановитьПуть("/a%2Fb")` считает `%` данными и создаёт `/a%252Fb`.
`УстановитьКодированныйПуть("/a%2Fb")` сохраняет `/a%2Fb`.

Серверная часть и её компоненты, запрос и фрагмент могут отсутствовать. При отсутствии метод возвращает
`Неопределено`, при наличии пустого компонента возвращает пустую строку.

| Строка | Метод | Результат |
| --- | --- | --- |
| `//host/path` | `ТекстПорта()` | `Неопределено` |
| `//host:/path` | `ТекстПорта()` | `""` |
| `/path` | `КодированныйХост()` | `Неопределено` |
| `///path` | `КодированныйХост()` | `""` |
| `/path` | `КодированнаяСтрокаЗапроса()` | `Неопределено` |
| `/path?` | `КодированнаяСтрокаЗапроса()` | `""` |
| `/path` | `КодированныйФрагмент()` | `Неопределено` |
| `/path#` | `КодированныйФрагмент()` | `""` |

Конструктор и методы изменения проверяют общую грамматику URI, но не ограничения конкретной схемы. Например,
`http:/path` синтаксически корректен, однако `СоответствуетСхеме()` вернёт `Ложь`, потому что у `http` нет хоста.

Конструктор проверяет форму процентных последовательностей, но декодирование UTF-8 выполняется при вызове
декодирующих методов. Поэтому успешно созданный объект всё ещё может вызвать `encoding.invalid` при обращении к
`Путь()`, `СтрокаЗапроса()`, `Фрагмент()` или другому декодированному представлению. Единой операции строгого
декодирования всех компонентов нет: проверяйте только те декодированные компоненты, которые использует приложение.

## Создание

```bsl
Новый URL(<Адрес> = Неопределено, <База> = Неопределено)
```

Полная диспетчеризация конструктора:

| `Адрес` | `База` | Поведение |
| --- | --- | --- |
| `Неопределено` | `Неопределено` | Создание пустой относительной ссылки |
| `Строка` или [`URL`](URL.md) | `Неопределено` | Создание независимого абсолютного или относительного URL |
| `Строка` или [`URL`](URL.md) | Абсолютная база | Разрешение по RFC 3986 § 5.2 |
| `Неопределено` | Заданная база | `argument.required` |
| Любая ссылка | Относительная база | `url.base_not_absolute` |

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Адрес | `Строка`, [`URL`](URL.md), `Неопределено` | Создаваемая ссылка |
| База | `Строка`, [`URL`](URL.md), `Неопределено` | Абсолютная база для относительной ссылки |

Конструктор возвращает новый [`URL`](URL.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип адреса или базы |
| `argument.required` | База задана без адреса |
| `url.base_not_absolute` | База не является абсолютной |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Адрес или база имеют недопустимый синтаксис |

```bsl
#Использовать url

Адрес = Новый URL("../users", "https://example.com/api/");
// https://example.com/users
```

## Общие свойства и представление

### ВСтроку

Возвращает текущее представление URL. Сразу после разбора оно совпадает с исходным написанием. После изменения
затронутый компонент может быть сериализован заново, а остальные компоненты сохраняют своё написание.

```bsl
.ВСтроку()
```

#### Возвращаемое значение

`Строка`: текущее представление URL.

### КодированноеПредставление

Возвращает ASCII-представление URL. Символы Unicode, включая символы хоста, преобразуются в UTF-8, после чего
каждый полученный байт записывается как `%HH`. Уже записанные последовательности `%HH` сохраняют регистр
шестнадцатеричных цифр.

```bsl
.КодированноеПредставление()
```

#### Возвращаемое значение

`Строка`: URL, состоящий из символов ASCII.

### Скопировать

Создаёт полностью независимую изменяемую копию.

```bsl
.Скопировать()
```

#### Возвращаемое значение

Новый [`URL`](URL.md) с независимым состоянием.

### ЯвляетсяАбсолютным

Проверяет только наличие схемы. Например, `http:/path` является абсолютным URI, хотя не соответствует схеме `http`.

```bsl
.ЯвляетсяАбсолютным()
```

#### Возвращаемое значение

`Булево`: `Истина`, если ссылка содержит схему.

## Схема URL

### СоответствуетСхеме

Возвращает `Булево` по результату проверки дополнительных ограничений схем `http`, `https`,
`ws`, `wss` и `ftp`. Для относительной ссылки или неизвестной схемы возвращает `Истина`. Известные схемы требуют
непустой хост; указанный непустой порт должен входить в диапазон `0..65535`. `ws` и `wss` запрещают данные
пользователя и фрагмент. Вызывайте метод после создания или изменения URL, если нужны ограничения схемы.

```bsl
.СоответствуетСхеме()
```

Успешный конструктор, `РазборURL.ПопытатьсяРазобрать()` и `РазборURL.ЭтоКорректнаяСсылка()` не заменяют эту
проверку. Метод проверяет структуру известной схемы, но не определяет доверие к узлу и не заменяет
ограничения приложения на сетевые адреса.

#### Возвращаемое значение

`Булево`: `Истина`, если ссылка соответствует ограничениям своей схемы.

### Схема

Возвращает схему без завершающего `:`.

```bsl
.Схема()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если ссылка относительная и не содержит схемы.

### УстановитьСхему

Устанавливает схему абсолютного URL без завершающего `:`.

```bsl
.УстановитьСхему(<Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Новая схема |

#### Возвращаемое значение

Тот же объект [`URL`](URL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |
| `url.invalid_scheme` | Значение не соответствует грамматике схемы |

## Серверная часть URL

### КодированнаяСервернаяЧасть

Возвращает кодированные данные пользователя, хост и порт без начального `//`. Путь, запрос и фрагмент не входят.

```bsl
.КодированнаяСервернаяЧасть()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если серверная часть отсутствует.

### СервернаяЧасть

Возвращает декодированные данные пользователя, хост и порт без начального `//`. Путь, запрос и фрагмент не входят.

```bsl
.СервернаяЧасть()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если серверная часть отсутствует.

#### Ошибки

| Код | Условие |
| --- | --- |
| `encoding.invalid` | Один из декодируемых компонентов содержит некорректный UTF-8 |
| `idna.data.invalid` | Встроенные данные IDNA повреждены или несовместимы |

### УстановитьКодированнуюСервернуюЧасть

Устанавливает кодированную серверную часть без изменения исходного написания.

```bsl
.УстановитьКодированнуюСервернуюЧасть(<Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, `Неопределено` | Кодированная серверная часть либо признак её удаления |

#### Возвращаемое значение

Тот же объект [`URL`](URL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Нарушены синтаксис, форма `%HH`, форма хоста или IP-литерала |

#### Поведение

`Неопределено` удаляет серверную часть вместе с её подкомпонентами.

### УстановитьСервернуюЧасть

Разбирает и устанавливает декодированную серверную часть. Символы `@`, `:`, `[` и `]` интерпретируются как
структурные разделители.

```bsl
.УстановитьСервернуюЧасть(<Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, `Неопределено` | Серверная часть либо признак её удаления |

#### Возвращаемое значение

Тот же объект [`URL`](URL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |
| `url.invalid_syntax` | Значение содержит недопустимую кодовую точку Unicode |
| `url.invalid_authority` | Нарушена структура серверной части |
| `url.invalid_host` | Некорректен хост |

#### Поведение

`Неопределено` удаляет серверную часть вместе с данными пользователя, хостом и портом.

## Данные пользователя URL

### ДанныеПользователя

Возвращает строго декодированные данные пользователя без завершающего `@`.

```bsl
.ДанныеПользователя()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если данные пользователя отсутствуют.

#### Ошибки

| Код | Условие |
| --- | --- |
| `encoding.invalid` | Процентные байты не образуют корректную последовательность UTF-8 |

### КодированныеДанныеПользователя

Возвращает кодированные данные пользователя без завершающего `@`.

```bsl
.КодированныеДанныеПользователя()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если данные пользователя отсутствуют.

### ВСтрокуБезДанныхПользователя

Возвращает строку URL без кодированных данных пользователя и разделителя `@`.

```bsl
.ВСтрокуБезДанныхПользователя()
```

#### Возвращаемое значение

`Строка`: URL без имени пользователя и пароля. Остальные компоненты сохраняются без изменений.

#### Поведение

Метод не гарантирует безопасное журналирование: секреты могут оставаться в пути, запросе и фрагменте.

### ВСтрокуСМаскированнымПаролем

Возвращает строку URL, в которой текст после первого буквального `:` в данных пользователя заменён на `*****`.
Если буквального `:` нет, строка возвращается без изменений. Кодированный `%3A` разделителем не считается.

```bsl
.ВСтрокуСМаскированнымПаролем()
```

#### Возвращаемое значение

`Строка`: URL с замаскированным паролем. Имя пользователя и остальные компоненты сохраняются без изменений.

#### Поведение

Метод не гарантирует безопасное журналирование: секреты могут оставаться в пути, запросе и фрагменте.

### УстановитьДанныеПользователя

Кодирует и устанавливает полные данные пользователя.

```bsl
.УстановитьДанныеПользователя(<Значение>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, `Неопределено` | Данные пользователя либо признак их удаления |

#### Возвращаемое значение

Тот же объект [`URL`](URL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |
| `url.invalid_syntax` | Значение содержит недопустимую кодовую точку Unicode |

#### Поведение

При отсутствии серверной части она создаётся с пустым хостом. `Неопределено` удаляет имя и пароль.

| Параметр | Тип | Описание |

## Хост URL

`Хост()` возвращает декодированное имя, `КодированныйХост()` сохраняет процентное кодирование, а `IDNХост()`
преобразует международное доменное имя в Punycode для DNS. `КодированноеПредставление()` кодирует весь URI в
ASCII, но не заменяет доменное имя на Punycode.

Чтобы получить полностью кодированную строку с DNS-совместимым хостом, создайте копию, установите в неё результат
`IDNХост()` и вызовите `КодированноеПредставление()`:

```bsl
#Использовать url

Адрес = Новый URL("https://пример.рф/путь");
СетевойАдрес = Адрес.Скопировать();
СетевойАдрес.УстановитьХост(Адрес.IDNХост());

Сообщить(СетевойАдрес.КодированноеПредставление());
// https://xn--e1afmkfd.xn--p1ai/%D0%BF%D1%83%D1%82%D1%8C
```

Используйте исходное, процентно-кодированное или Punycode-представление в соответствии с требованиями клиента,
которому передаётся адрес.

### IDNХост

Возвращает ASCII-совместимое представление хоста. Международное доменное имя строго
проверяется по [UTS #46](https://www.unicode.org/reports/tr46/) и преобразуется в Punycode с непереходной
обработкой. ASCII-метки проверяются по правилам `CheckHyphens` и `UseSTD3ASCIIRules`: разрешены только буквы,
цифры и дефис, дефис запрещён в начале и конце, а последовательность `--` в позициях 3 и 4
разрешена только в префиксе `xn--`.
Метка не может превышать 63 октета, а полное ASCII-имя без завершающей точки - 253 октета. IP-адрес
возвращается без изменений.

Метка означает часть доменного имени между точками, а октет в этом разделе означает один байт ASCII.
Непереходная обработка не заменяет специальные символы устаревшими ASCII-аналогами, например `ß` не превращается
в `ss`. `CheckHyphens` проверяет положение дефисов, а `UseSTD3ASCIIRules` запрещает в ASCII-метках символы, кроме
букв, цифр и дефиса.

```bsl
.IDNХост()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если хост отсутствует.

#### Ошибки

| Код | Условие |
| --- | --- |
| `encoding.invalid` | Процентные байты имени не образуют корректную последовательность UTF-8 |
| `url.invalid_host` | Зарегистрированное имя не соответствует требованиям IDNA |
| `idna.data.invalid` | Встроенные данные IDNA повреждены или несовместимы |

## Путь URL

### ДобавитьСегментПути

Кодирует значение как один сегмент и добавляет его в конец пути. Символ `/` внутри значения кодируется как `%2F`.

## Строка запроса URL

`СтрокаЗапроса()` работает со всем запросом как с компонентом URI и оставляет `+` без изменений.
`ПараметрыЗапроса()` разбирает запрос как форму `application/x-www-form-urlencoded`, где `+` означает пробел.
Сохранённая коллекция параметров является живым представлением запроса, а не снимком. Она увидит последующие
изменения URL и изменения через другую связанную коллекцию при следующем вызове своего метода.

Чтение параметров сохраняет исходную строку запроса. Любой изменяющий метод коллекции сериализует весь запрос
заново по правилам формы. При этом, например, `%20` станет `+`, а часть `flag` без `=` станет `flag=`.

Возвращает связанную с URL коллекцию параметров формы. Чтение коллекции не изменяет исходное написание запроса;
при изменении коллекции запрос сериализуется по алгоритму
[WHATWG `application/x-www-form-urlencoded`](https://url.spec.whatwg.org/#application-x-www-form-urlencoded).


Каждый вызов возвращает новый объект коллекции, но все такие объекты читают и изменяют запрос одного владельца.

## Разрешение ссылок

### Разрешить

Разрешает ссылку относительно текущего URL по
[RFC 3986 § 5.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-5.2).

```bsl
.Разрешить(<Ссылка>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Ссылка | `Строка`, [`URL`](URL.md) | Относительная или абсолютная ссылка |

#### Возвращаемое значение

Новый независимый абсолютный [`URL`](URL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип ссылки |
| `url.base_not_absolute` | Текущий URL не является абсолютной базой |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Переданная строка имеет недопустимый синтаксис |

### СделатьОтносительным

Строит детерминированную URI-ссылку на абсолютную цель относительно текущего URL.
Результат выбирается так, чтобы `Разрешить()` восстановил цель. Если это невозможно, возвращается абсолютная цель.

```bsl
.СделатьОтносительным(<Цель>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Цель | `Строка`, [`URL`](URL.md) | Абсолютная целевая ссылка |

#### Возвращаемое значение

Новый независимый [`URL`](URL.md): относительная ссылка либо нормализованная абсолютная цель.

Примеры выбранной формы результата:

| База | Цель | Результат |
| --- | --- | --- |
| `http://e/a/` | `http://e/a/b` | `b` |
| `http://e/a/b/file` | `http://e/a/c/file2` | `../c/file2` |
| `http://e/a/b` | `http://e/a/` | `./` |
| `http://e/a/` | `https://e/a/b` | `https://e/a/b` |
| `http://e/a/` | `http://other/a/b` | `http://other/a/b` |

База с завершающим `/` рассматривается как каталог. Если схема или серверная часть не позволяют построить
относительную ссылку с тем же смыслом, возвращается абсолютная цель.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип цели |
| `argument.invalid_value` | Цель не является абсолютной |
| `url.base_not_absolute` | Текущий URL не является абсолютной базой |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Переданная строка имеет недопустимый синтаксис |

## Нормализация и сравнение

Методы сравнивают только представления URI. Они не выполняют сетевые запросы и не гарантируют, что два URI ведут
на один ресурс.

### Нормализованный

Возвращает новый URL после общей нормализации по
[RFC 3986 § 6.2.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-6.2.2):

- приводит схему и ASCII-символы хоста к нижнему регистру;
- приводит шестнадцатеричные цифры в `%HH` к верхнему регистру;
- декодирует `%HH`, если байт обозначает незарезервированный символ;
- сворачивает полные сегменты `.` и `..`, сохраняя смысл относительной ссылки;
- удаляет пустой порт и его разделитель по
  [RFC 3986 § 3.2.3](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.2.3).

```bsl
.Нормализованный()
```

#### Возвращаемое значение

Новый независимый нормализованный [`URL`](URL.md).

### НормализованныйДляСхемы

Сначала выполняет все преобразования `Нормализованный()`, затем применяет правила схемы из
[RFC 3986 § 6.2.3](https://www.rfc-editor.org/rfc/rfc3986.html#section-6.2.3):

- удаляет стандартный порт `80` для `http` и `ws`, `443` для `https` и `wss`, `21` для `ftp`;
- заменяет пустой путь на `/` для `http`, `https`, `ws` и `wss`, если определена серверная часть.

Для неизвестной схемы результат совпадает с `Нормализованный()`.

```bsl
.НормализованныйДляСхемы()
```

#### Возвращаемое значение

Новый независимый [`URL`](URL.md), нормализованный с учётом схемы.

### Равен

Сравнивает исходные написания текущего URL и другой URI-ссылки без нормализации.

```bsl
.Равен(<Другое>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другое | `Строка`, [`URL`](URL.md) | Сравниваемая ссылка |

#### Возвращаемое значение

`Булево`: `Истина`, если исходные строки совпадают.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Переданная строка имеет недопустимый синтаксис |

### РавенПоКомпонентам

Проверяет совпадение структуры и кодированных данных двух ссылок. Метод вызывает `Сравнить()` и возвращает
`Истина`, если результат равен нулю.

Например, `HTTP://Example.com/a%2f` равен по компонентам `http://example.com/a%2F`, а `/%7E` не равен `/~`.

```bsl
.РавенПоКомпонентам(<Другое>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другое | `Строка`, [`URL`](URL.md) | Сравниваемая ссылка |

#### Возвращаемое значение

`Булево`: `Истина`, если кодированные компоненты равны по указанным правилам.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Переданная строка имеет недопустимый синтаксис |

### Сравнить

Сравнивает ссылки для сортировки по кодированным компонентам. Регистр схемы, хоста и шестнадцатеричных цифр в
`%HH` не учитывается. Остальные символы сравниваются буквально, без нормализации.

```bsl
.Сравнить(<Другое>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другое | `Строка`, [`URL`](URL.md) | Сравниваемая ссылка |

#### Возвращаемое значение

`Число`: меньше нуля, если текущий URL должен идти раньше; больше нуля, если позже; ноль, если ссылки равны по
компонентам. Конкретное значение числа не определено.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Переданная строка имеет недопустимый синтаксис |

### Эквивалентен

Проверяет эквивалентность по общим правилам URI, не зависящим от схемы. Перед сравнением обе ссылки проходят
`Нормализованный()`.

Например, `HTTP://Example.com/a/../%7E` эквивалентен `http://example.com/~`. При этом `http://example.com` не
эквивалентен `http://example.com:80/`, поскольку стандартный порт и пустой путь зависят от схемы.

```bsl
.Эквивалентен(<Другое>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другое | `Строка`, [`URL`](URL.md) | Сравниваемая ссылка |

#### Возвращаемое значение

`Булево`: `Истина`, если ссылки эквивалентны после общей нормализации.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Переданная строка имеет недопустимый синтаксис |

### ЭквивалентенДляСхемы

Проверяет эквивалентность с учётом правил известных схем. Перед сравнением обе ссылки проходят
`НормализованныйДляСхемы()`.

Например, `http://example.com` эквивалентен для схемы `http://example.com:80/`: порт `80` удаляется, а пустой путь
заменяется на `/`. Для неизвестной схемы метод работает так же, как `Эквивалентен()`.

```bsl
.ЭквивалентенДляСхемы(<Другое>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другое | `Строка`, [`URL`](URL.md) | Сравниваемая ссылка |

#### Возвращаемое значение

`Булево`: `Истина`, если ссылки эквивалентны после нормализации с учётом схемы.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |
| [Коды разбора URI](КодыОшибокURL.md#коды-разбора-uri) | Переданная строка имеет недопустимый синтаксис |

## Примеры

Безопасное добавление одного сегмента пути:

```bsl
#Использовать url

Адрес = Новый URL("https://example.com/files");
Адрес.ДобавитьСегментПути("reports/2025.pdf");

Сообщить(Адрес.ВСтроку());
// https://example.com/files/reports%2F2025.pdf
```

Строка запроса и параметры формы:

```bsl
#Использовать url

Адрес = Новый URL("https://example.com/?q=hello+world");

Сообщить(Адрес.СтрокаЗапроса());
// q=hello+world

Сообщить(Адрес.ПараметрыЗапроса().Получить("q"));
// hello world
```

Представления международного доменного имени:

```bsl
#Использовать url

Адрес = Новый URL("https://пример.рф/");

Сообщить(Адрес.Хост());
// пример.рф

Сообщить(Адрес.КодированныйХост());
// %D0%BF%D1%80%D0%B8%D0%BC%D0%B5%D1%80.%D1%80%D1%84

Сообщить(Адрес.IDNХост());
// xn--e1afmkfd.xn--p1ai
```

Сравнение после общей нормализации и с учётом схемы:

```bsl
#Использовать url

Первый = Новый URL("http://example.com");
Второй = Новый URL("http://example.com:80/");

Сообщить(Первый.Эквивалентен(Второй));
// Ложь

Сообщить(Первый.ЭквивалентенДляСхемы(Второй));
// Истина
```
