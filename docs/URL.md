# URL

Изменяемый абсолютный URL с символами Unicode на основе
[RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html) и
[RFC 3987](https://www.rfc-editor.org/rfc/rfc3987.html). Все изменения атомарны: при ошибке объект сохраняет
прежнее состояние. Компоненты, которых операция не касается, сохраняют исходное написание.

## Создание

```bsl
Новый URL(<Адрес> = Неопределено, <База> = Неопределено)
```

Полная диспетчеризация конструктора:

| `Адрес` | `База` | Поведение |
| --- | --- | --- |
| `Неопределено` | `Неопределено` | Создание `http://localhost/` |
| Абсолютная `Строка`, [`URI`](URI.md) или [`URL`](URL.md) | `Неопределено` | Создание независимого URL |
| Относительная `Строка`, [`URI`](URI.md) или [`URL`](URL.md) | Абсолютная база | Разрешение по RFC 3986 § 5.2 |
| Относительная ссылка | `Неопределено` | `url.relative_without_base` |
| `Неопределено` | Заданная база | `argument.required` |
| Любая ссылка | Относительная база | `url.base_not_absolute` |

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Адрес | `Строка`, [`URI`](URI.md), [`URL`](URL.md), `Неопределено` | Создаваемая ссылка |
| База | `Строка`, [`URI`](URI.md), [`URL`](URL.md), `Неопределено` | Абсолютная база для относительной ссылки |

Конструктор возвращает новый [`URL`](URL.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип адреса или базы |
| `argument.required` | База задана без адреса |
| `url.relative_without_base` | Относительный адрес передан без базы |
| `url.base_not_absolute` | База не является абсолютной |
| Коды разбора URI | Адрес или база имеют недопустимый синтаксис |

```bsl
Адрес = Новый URL("../users", "https://example.com/api/");
// https://example.com/users
```

## Методы

### URI

Возвращает неизменяемый снимок текущего состояния.

```bsl
.URI()
```

#### Возвращаемое значение

Новый независимый [`URI`](URI.md), сохраняющий текущее исходное написание.

### ВСтроку

Возвращает URL в текущем исходном написании без потерь.

```bsl
.ВСтроку()
```

#### Возвращаемое значение

`Строка`: текущее представление URL.

### КодированноеПредставление

Возвращает ASCII-представление URL. Символы Unicode, включая символы хоста, преобразуются в UTF-8, после чего
каждый полученный байт записывается как `%HH`. Уже записанные последовательности `%HH` сохраняют регистр
шестнадцатеричных цифр.

```bsl
.КодированноеПредставление()
```

#### Возвращаемое значение

`Строка`: URL, состоящий из символов ASCII.

### Схема

Возвращает схему без завершающего `:`.

```bsl
.Схема()
```

#### Возвращаемое значение

`Строка`: схема абсолютного URL.

### СервернаяЧасть

Возвращает декодированную серверную часть без начального `//`.

```bsl
.СервернаяЧасть()
```

`Строка` или `Неопределено`, если серверная часть отсутствует.

#### Ошибки

| --- | --- |
| `encoding.invalid` | Один из декодируемых компонентов содержит некорректный UTF-8 |

```bsl

```

#### Возвращаемое значение

`Булево`: `Истина`, если порт указан, включая пустой порт.

### ЭффективныйПорт


#### Возвращаемое значение

`Число` или `Неопределено`, если схема неизвестна и явный непустой порт отсутствует.

#### Ошибки

| Код | Условие |
| --- | --- |
| `url.port.numeric_overflow` | Явный порт нельзя точно представить числом |

### ИспользуетСтандартныйПорт

```bsl

```

#### Возвращаемое значение

`Булево`: `Истина`, если URL использует стандартный порт известной схемы.

### ПараметрыЗапроса

Возвращает связанную с URL коллекцию параметров формы. Чтение коллекции не изменяет исходное написание запроса;
изменение сериализует его по алгоритму
[WHATWG `application/x-www-form-urlencoded`](https://url.spec.whatwg.org/#application-x-www-form-urlencoded).

```bsl
.ПараметрыЗапроса()
```

#### Возвращаемое значение

Новый объект [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md), связанный с текущим URL.

### УстановитьПараметрыЗапроса

Копирует самостоятельную или связанную коллекцию параметров в запрос URL. Последующие изменения
исходной коллекции не изменяют URL. Пустая коллекция удаляет компонент запроса.

```bsl
.УстановитьПараметрыЗапроса(<Значение>)
```

#### Параметры

| Имя | Тип | Описание |
| --- | --- | --- |
| Значение | [`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md) | Копируемая коллекция |

#### Возвращаемое значение

Тот же объект [`URL`](URL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |

### УстановитьСервернуюЧасть

Разбирает и устанавливает декодированную серверную часть. Символы `@`, `:`, `[` и `]` интерпретируются как
структурные разделители.

```bsl

```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, `Неопределено` | Серверная часть либо признак её удаления |

#### Возвращаемое значение

Тот же объект [`URL`](URL.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передан неподдерживаемый тип |
| `uri.invalid_syntax` | Значение содержит недопустимую кодовую точку Unicode |
| `uri.invalid_authority` | Нарушена структура серверной части |
| `uri.invalid_host` | Некорректен хост |
| `url.incompatible_components` | Серверная часть несовместима с текущим путём |

#### Поведение

`Неопределено` удаляет серверную часть вместе с данными пользователя, хостом и портом.

```bsl
Снимок = Адрес.URI();
```
