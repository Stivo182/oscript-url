# ФорматыПараметровЗапросаURL

Модуль возвращает значения форматов, которые принимает
[`ПараметрыЗапросаURL`](ПараметрыЗапросаURL.md).

## RFC3986

```bsl
ФорматыПараметровЗапросаURL.RFC3986()
```

Возвращает строку `RFC3986`. Это формат по умолчанию. Пробел кодируется как `%20`, а `+` воспринимается буквально.
При сериализации имён и значений без кодирования остаётся набор незарезервированных символов из
[RFC 3986 §2.3](https://www.rfc-editor.org/rfc/rfc3986.html#section-2.3):

```text
ALPHA / DIGIT / "-" / "." / "_" / "~"
```

RFC 3986 не устанавливает формат пар `имя=значение`. Имя `RFC3986` обозначает профиль библиотеки, основанный на
правилах процентного кодирования RFC 3986.

## ВебФорма

```bsl
ФорматыПараметровЗапросаURL.ВебФорма()
```

Возвращает строку `FormUrlEncoded`. Формат следует алгоритму
[WHATWG `application/x-www-form-urlencoded`](https://url.spec.whatwg.org/#application-x-www-form-urlencoded):
пробел кодируется как `+`, исходный `+` как `%2B`, а каждая пара получает строковое значение.
