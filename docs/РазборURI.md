# РазборURI

Публичный модуль для безопасного разбора URI-ссылок без исключения как обычного результата ошибки ввода.
Синтаксис проверяется тем же конструктором [`URI`](URI.md) по
[RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html) и
[RFC 3987](https://www.rfc-editor.org/rfc/rfc3987.html).

## ПопытатьсяРазобрать

```bsl
Ссылка = РазборURI.ПопытатьсяРазобрать(Значение);
```

Возвращает новый [`URI`](URI.md), если строка корректна, либо `Неопределено` при ожидаемой ошибке разбора или
неправильном типе аргумента. Неожиданная внутренняя ошибка без машинного кода вызывается повторно.

## ЭтоКорректнаяСсылка

```bsl
Корректна = РазборURI.ЭтоКорректнаяСсылка(Значение);
```

Возвращает `Булево`: `Истина`, если `ПопытатьсяРазобрать()` вернул объект [`URI`](URI.md).
