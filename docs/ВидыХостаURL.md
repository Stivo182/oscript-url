# ВидыХостаURL

Публичный модуль содержит значения, возвращаемые методом `URL.ВидХоста()`.
Классификация соответствует альтернативам `host` из
[RFC 3986 § 3.2.2](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.2.2).

| Функция | Значение | Представление хоста |
| --- | --- | --- |
| `ЗарегистрированноеИмя()` | `RegName` | Зарегистрированное имя, включая пустой хост |
| `IPv4()` | `IPv4` | IPv4-адрес |
| `IPv6()` | `IPv6` | IPv6-литерал в квадратных скобках |
| `IPvFuture()` | `IPvFuture` | IPvFuture-литерал в квадратных скобках |

При отсутствии серверной части метод `ВидХоста()` возвращает `Неопределено`.
Зарегистрированное имя является хостом, который не распознан как IP-адрес. Обычно это доменное имя, но общая
грамматика URI допускает и другие имена. Пустой хост в определённой серверной части также относится к этому виду.

Сравнивайте результат с функцией модуля, а не со строковым литералом:

```bsl
#Использовать url

Адрес = Новый URL("https://127.0.0.1/");

Если Адрес.ВидХоста() = ВидыХостаURL.IPv4() Тогда
    Сообщить("Хост является IPv4-адресом");
КонецЕсли;
```
