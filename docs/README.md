# Документация программного интерфейса

Публичный программный интерфейс пакета `url` предназначен для работы с URI-ссылками и изменяемыми абсолютными URL,
в том числе содержащими символы Unicode. Сетевой ввод-вывод не выполняется. Синтаксис основан на
[RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html) и
[RFC 3987](https://www.rfc-editor.org/rfc/rfc3987.html), а обработка параметров формы — на
[WHATWG URL §5](https://url.spec.whatwg.org/#application-x-www-form-urlencoded).
