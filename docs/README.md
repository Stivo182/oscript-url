# Документация программного интерфейса

Публичный программный интерфейс пакета `url` предназначен для работы с URI-ссылками и изменяемыми абсолютными URL
без сетевого ввода-вывода. Синтаксис URI основан на RFC 3986, а обработка параметров формы - на WHATWG URL §5.

## Руководства

- [Установка и основные сценарии](../README.md)

## Классы

- [URI](URI.md) - неизменяемая URI-ссылка с сохранением исходного написания
- [URL](URL.md) - изменяемый абсолютный URL и атомарные операции над компонентами
- [ПараметрыURL](ПараметрыURL.md) - упорядоченная коллекция параметров формы, связанная с запросом URL

## Модули

- [КодированиеURL](КодированиеURL.md) - кодирование компонентов и параметров формы
- [КодыОшибокURL](КодыОшибокURL.md) - стабильные машинные коды ошибок
